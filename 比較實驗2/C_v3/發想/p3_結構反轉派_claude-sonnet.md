# 概念名稱
《黃線》

# 一句話故事
黑狗發現破掉的外套被人用黃線補好，氣沖沖要揪出「多管閒事的人」；一路推理，線索回看才發現，最不會縫的人縫了它，而他嘴上一直吼的「我才不在乎」，正是他最在乎的事。

# 開場 Hook（前 10 秒）
教室，早上。黑狗把一件校外套「啪」地攤在桌上，袖口有一道歪歪扭扭、像打叉的亮黃色縫線。他環顧全班，一個字一個字：「誰、縫、的？給我站出來。」全班安靜。**背景門口**，老蔡靠著門框吃早餐，肩上小音響的提帶也有一小段黃線（只出現約 2 秒、略失焦，不強調）。

# 主角目標與主要阻礙
- 目標：揪出偷偷幫他補外套的人，叫對方「以後別多管閒事」。
- 阻礙：(1) 他先入為主認定「縫得這麼醜一定是女生」，抓錯人；(2) 他嘴硬，不肯講外套為什麼破、昨天把它藏去哪；(3) 真相需要他承認一件丟臉的事。

# 核心故事引擎
**偵探式的「假裝不在乎」**：黑狗每推進一步，輝仔就多撿到一個物證，每個物證都在逼黑狗回想昨天的事。他越凶，越暴露他很在意。
- 偏見推理失敗（策略一：找「手巧的女生」）→ 物證推理（策略二：看縫線、看灰塵）→ 直接堵人（策略三）。
- 觀眾以為在查「誰縫的」，其實是在查「黑狗為什麼這麼生氣」。這是兩層問題，第二層到結尾才揭曉。

# 主要驚喜或情緒回報
- 驚喜 1：全班最手巧的阿蓮「不會縫衣服」，她的包包肩帶是用束線帶綁的。她手巧，但不是「女生就會縫」。
- 驚喜 2：縫的人是老蔡，而且他縫得很爛、穿不進針。
- 情緒回報：黑狗自己說出「他們笑的是我」。老蔡沒有替他說答案，只指出一個行為（「你剛剛說了四次不在乎。」），讓黑狗自己接住。

# 結尾畫面
操場邊台階，四人並排坐著，黑狗低頭，在外套袖口自己縫下第二個黃色小叉，叉得一樣歪。他抬頭，看見老蔡從袋子裡拿出一疊破掉的體育課背心，輕輕放在他腿上。黑狗愣住，苦笑。

# 伏筆與回收
- 伏筆 A：鉤子背景，老蔡音響提帶上的黃色叉狀縫線。回收：器材室揭曉時鏡頭回到同一條提帶，兩者同款，觀眾「原來早就看過」。
- 伏筆 B：外套背面的白色石灰粉。回收：推出外套昨天被藏在器材室，也逼出黑狗說謊。
- 伏筆 C：阿蓮手上的機油痕與束線帶肩帶。回收：她不會縫，從而排除她，同時打破「手巧＝會縫＝女生」。
- 伏筆 D：黑狗「我不在乎」的口頭禪，共四次。回收：老蔡只問次數，不下結論。
- 伏筆 E：輝仔低聲提到「同一種針法」。回收：他早就看出誰縫的，但選擇等黑狗自己走到那一步（符合「話少心細、想太多」）。

# 片尾投票題（題目＋預期詞＋第 2 集怎麼用）
- 題目：「黑狗袖口那一小塊補丁，你覺得縫成什麼圖案最適合？寫一個詞。」
- 預期詞：閃電／愛心／骨頭／反光（任何具象圖案）。
- 第 2 集用法：黑狗外套袖口出現這個補丁圖案，成為他的標記。若票數最高為「反光」，剛好能自然接到交通安全主題（反光條）；其他詞則當成他的外套記號，一個畫面上的小細節即可。

# 適合 AI 影片生成的理由
- 3 個場景、4 個角色，全程慢速走動與坐姿，沒有追逐、打鬥。
- 核心視覺只有「一件外套＋黃色縫線」，特寫穩定、可重複使用。
- 反轉靠「同一道黃線兩次出現」的畫面，不需要看懂文字。
- 對白短，一人一句，容易對口型與剪接。

# 自評：最大的風險
伏筆全靠「黃色叉狀縫線」與「石灰粉」這類小細節，若 AI 生成的縫線顏色、花樣在不同鏡頭間漂移，回看成立的反轉會失效，因此必須在每次出現時用特寫並後製校色鎖定。
