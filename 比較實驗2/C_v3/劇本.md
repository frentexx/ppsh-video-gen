# 片名
黃線

# 一句話故事
黑狗把裂開的外套偷偷藏進器材室，隔天它卻被人用歪歪的黃線補好、摺好放回桌上；他氣沖沖追查，縫的人竟是最不會縫的老蔡，而黑狗連吼四次的「我不在乎」，底下其實是他說得出口的兩個字：丟臉。

# 逐場劇本

## 場次 1・外・操場台階・昨日傍晚（0–6 秒）
夕陽。黑狗站上台階第二階，面對三個旁觀者：兩位學弟妹，和一位西瓜皮頭的同班男生（皆無台詞）。他雙手往上甩出一個帥氣姿勢。
（音效）嘶——布料裂開聲。
特寫：外套袖口裂出一道彎彎的口子，形狀像一張咧開的嘴。
三人同時摀嘴，肩膀抖動，不出聲。黑狗僵住，手慢慢放下，拳頭握緊。
他脫下外套，捲成一團抱在胸前，快步走向旁邊的器材室鐵門（門口地上散著白色石灰粉），推門進去，門在身後關上。

## 場次 2・內・教室・隔天早晨（6–78 秒）
黑狗走進教室，外套摺得整整齊齊，放在他的桌上。他抖開外套攤平：袖口裂縫被補好，縫線是亮黃色，一個個歪歪的打叉。前排的西瓜皮頭同學瞄到外套，立刻低頭憋笑；黑狗瞪過去，同學把臉埋進課本。
教室門口，老蔡提著一個亮黃色大帆布袋慢慢走過，藍白拖，肩上小音響。（全身入鏡，清楚，但沒有任何人注意。）

黑狗：啥人縫的？給我站出來！
黑狗：縫這麼醜，擺明是看我笑話！
黑狗：我不在乎啦，我只是要知道是誰。
黑狗：會針線的一定是女生。阿蓮，是你吧？
阿蓮坐在座位上，正用小螺絲起子修一把斷骨的折疊傘，沒抬頭。她攤開手給黑狗看：指縫有黑色機油。
阿蓮：我手巧，但我只會修，不會縫。
黑狗：不然咧？男生誰會縫這個！
輝仔：針線沒有分男女，只有分會不會。
輝仔拿起外套，指著袖口。
輝仔：每一針都往右歪，同一個人縫的。
輝仔用指尖捏起外套背面的白色粉末。
輝仔：石灰粉，只有器材室才有。
黑狗握緊拳頭，指節發白。
黑狗：我昨天沒去器材室！我根本不在乎誰縫的！
輝仔看著他的拳頭，沒有再說話。

## 場次 3・內・器材室・同日中午（78–152 秒）
黑狗走在最前面，阿蓮、輝仔跟在後面。器材室門半開，球籃、墊子；一個背影坐在矮凳上低頭縫東西，腳邊放著那個亮黃色帆布袋。
黑狗：我說了，我不在乎！
背影轉過身：是老蔡，嘴裡咬著線頭，手上一件破掉的體育背心，針怎麼都穿不進去。帆布袋沒拉緊，袋口露出一大捲亮黃色的線，與外套縫線同色。
老蔡：來得正好，針穿不進去，幫我一下。
黑狗：你都看到了對不對！全部人都在笑我，我才不在乎！
他的拳頭抖著。老蔡放下針線，看著他。
老蔡：你剛剛講幾遍「不在乎」？
輝仔：四次。
老蔡：那你手抖啥？
黑狗低頭看自己的拳頭。
老蔡：你到底是在氣啥？
黑狗沉默很久，聲音變小。
黑狗：我不是氣，是丟臉。昨天袖子在大家面前破掉，我好見笑。
他的拳頭一點一點鬆開，手心有被指甲壓出的紅印。
阿蓮走過去，從老蔡手裡拿過針和線，一起遞到黑狗面前。
阿蓮：給你。不是因為你是男生，是因為它歪了。
黑狗接過針線，視線飄開，不太敢看她。
黑狗：阿蓮，早上那個……歹勢啦，是我亂講。
阿蓮：嗯。針尖朝外。

## 場次 4・外・操場台階・同日傍晚（152–180 秒）
夕陽，與開場同一階台階。黑狗坐著，外套鋪在膝上，在老蔡那個歪叉旁邊縫下第二個黃色小叉，一樣歪。
阿蓮拿著針，怎麼都穿不進去，皺眉。
阿蓮：穿不進去。
輝仔：我來。
輝仔接過針，穿好，還給她。
黑狗：男生也會縫啦，只是縫得有點歪。
老蔡走過來，藍白拖「啪嗒」。
老蔡：我縫了一整個晚上。
他把一疊破掉的體育背心放在黑狗腿上。
老蔡：還有三十件，免急。
黑狗看著背心，愣了兩秒，抬頭。
黑狗：免驚啦。
（後製字卡）黑狗的袖口，補丁要縫成什麼圖案？寫一個詞。

# 片尾投票題
- 題目：黑狗袖口那一塊補丁，你覺得縫成什麼圖案最適合？寫一個詞。
- 預期會出現的詞：閃電、愛心、骨頭、反光。
- 第 2 集怎麼放進去：黑狗外套袖口出現這個圖案的補丁，成為他的記號。若最多人寫「反光」，剛好接到交通安全主題的反光條；其他詞就當外套上的一個小細節。

# 伏筆與回收
- 開場石灰粉（器材室門口）→ 外套背面沾到白粉 → 輝仔驗出「只有器材室才有」，逼出黑狗說謊。
- 開場黑狗把外套藏進器材室 → 隔天外套被摺好放回桌上、已補好（誰補的？）。
- 老蔡提著亮黃色大帆布袋走過教室門口（第一次，不顯眼）→ 器材室同一個帆布袋放在腳邊，袋口露出一大捲亮黃線，與外套縫線同色（回看成立）。
- 歪歪的打叉針法（輝仔指出）→ 老蔡手上背心的針法一樣歪 → 結尾黑狗縫下的第二個叉也一樣歪。
- 袖口裂成「咧嘴」形狀＋西瓜皮頭同學憋笑（開場、教室）→ 黑狗說出「昨天袖子在大家面前破掉，我好見笑」。
- 黑狗的拳頭：說「不在乎」四次時握緊或發抖（教室、器材室口、爆發）→ 說出「丟臉」後鬆開。
- 「穿不進針」：老蔡穿不進，結尾阿蓮穿不進、輝仔幫她。「手巧」「會縫」與性別無關。
- 阿蓮修折疊傘、機油手 → 她只會修，不會縫；黑狗道歉時，她只冷冷提醒「針尖朝外」。
- 黑狗「男生誰會縫這個」→ 結尾「男生也會縫啦，只是縫得有點歪」。
- 台階：開場在台階出糗，結尾在同一台階縫補。
