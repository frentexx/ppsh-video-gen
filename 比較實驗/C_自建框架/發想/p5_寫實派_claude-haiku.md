# 概念名稱

**《車棚裡的那一下》**（第 1 集暫名：鏈條掉了）

# 一句話故事

黑狗在上學路上腳踏車鏈條掉了，他嘴硬說自己搞得定，結果在阿蓮和輝仔面前越修越丟臉；他終於承認不是氣車，是怕被看見不會修，而阿蓮的扳手、老蔡的一句話，讓他第一次把「女生不會修車」的話收回來。

# 開場 Hook（前 10 秒觀眾看到什麼）

田邊的柏油路，清晨，黑狗正用力踩腳踏車。「喀」一聲，鏈條掉在地上，車身歪向水溝。他蹲下，手伸進鏈條裡，油黑了一手。他抬頭對著鏡頭（觀眾）說：「免驚啦！」然後鏈條又掛回去又掉下來。遠景，阿蓮騎車經過，停在他旁邊，什麼都不說，從書包拿出一把小扳手，蹲下，三秒裝好。黑狗臉紅，嘴巴還在硬：「我本來就會啦。」

觀眾看到的是：一個嘴硬的男生，和一個不說話卻能做事的女生。懸念是：他會不會承認。

# 主角目標與主要阻礙

- **目標**：黑狗想把車自己修好，證明自己「會」，不想在阿蓮和同學面前丟臉。
- **主要阻礙**：他其實不會修，又不肯求助；他對阿蓮說的「女生不用會這個啦」是自己先堵死了求助的路。
- **次要阻礙**：輝仔一直在旁邊看，不講話，讓黑狗更不自在。老蔡路過只丟一句話，但剛好戳中他。

# 核心故事引擎

「嘴硬」是引擎。每次黑狗說一句硬話，情勢就往下掉一格：

1. 他說「女生不用會」→ 阿蓮不吵，只說「我家從小就修，跟性別沒關係」，然後騎走。他在路邊沒面子。
2. 他一個人修不好 → 只能在車棚硬撐，越急越弄不好。
3. 老蔡看一眼，不講道理，只問「黑狗，車惹你喔？」他說「沒有」，老蔡看著他發紅的耳朵說「丟臉喔？」——一句就點到。
4. 阿蓮回來拿忘掉的東西，看見他卡住，不笑，只把扳手遞過去說「螺絲要先鬆再轉」。黑狗要硬撐，她不爭，只把手穩住讓他看。他這時才承認：「我剛那樣講，是因為我也不會啊。」

社會情緒能力的演出點：觀眾看到的是「生氣（對車、對阿蓮）→ 嘴硬 → 丟臉 → 承認」，全部靠動作和表情，不靠老師講道理。

# 主要驚喜或情緒回報

- **驚喜**：黑狗一開始罵的是車，觀眾以為他在生車的氣；真正的答案在第四個節拍，他其實是怕被看到不會。
- **情緒回報**：黑狗在教室把扳手還給阿蓮，說「借你的」。阿蓮只回：「你手還是黑的。」全班小笑，黑狗也笑了，而且沒有再說硬話。觀眾會覺得他終於放下那層面子。
- 阿蓮的「女生就該怎樣」不被說教式地打臉，而是用一句「跟性別沒關係」和一次示範讓觀眾自己看見。

# 結尾畫面

教室早自習，黑狗把扳手放到阿蓮桌上，手上還有油漬。他回座位，輝仔在手機記事本打了一行字（畫面不出現可讀文字，由後製字卡補上）：「今天出糗了，還好。」老蔡的小音響放著沒有歌名的純音樂。畫面停在片尾投票字卡。

# 伏筆與回收

1. **輝仔的手機記事本**：第 1 節拍，他在路上拿出手機，看了一眼又收起來（畫面不顯示內容）。結尾回收為「今天出糗了，還好」，呼應黑狗的丟臉。
2. **阿蓮的小扳手**：開場就出現，她從書包拿出來。第 5 節拍她把扳手穩住讓黑狗自己轉；結尾黑狗還回去，回收為「借你的」。
3. **老蔡的小音響**：第 4 節拍放純音樂，結尾再放一次，讓觀眾感覺老蔡一直在場，只是不多說。
4. **「螺絲要先鬆再轉」**：阿蓮的第一句修車知識，在第 5 節拍被黑狗照做，證明她不是只會嘴上說。

# 片尾投票題

- **題目**：「老蔡下一集騎什麼出場？」（沿用原企劃題目）
- **預期會出現的詞**：機車、摩托車、腳踏車、三輪車、拖鞋（老蔡的藍白拖是他的符號，學生可能亂寫）
- **第 2 集怎麼放進去**：
  - 若最多人寫「機車」或「摩托車」：第 2 集老蔡騎機車帶大家談交通安全，全員戴安全帽，無照騎車不得出現。機車留給第 2 集，符合本集不騎機車的設定。
  - 若最多人寫「腳踏車」：老蔡跟黑狗一起騎車上學，延續本集的車，第 2 集聚焦「一起騎」而不是「騎多快」。
  - 若寫「三輪車」或「拖鞋」：當作玩笑細節，老蔡在第 2 集用這個出場，但仍要符合硬規格（無追逐、無危險騎乘）。

# 適合 AI 影片生成的理由

- **場景少**：只有田邊路、車棚、教室三個場景，符合「最多 3 個」的硬規格。
- **人物少且清楚**：有台詞的只有黑狗、阿蓮、輝仔、老蔡四人，不超過 5 人，且同一時間只有一個人說話。
- **動作慢、靜態多**：修鏈條、扳手夾螺絲、看耳朵、拿書包都是近景慢動作，不需要追逐或快速鏡頭運動，AI 比較穩。
- **情緒靠表情**：嘴硬、臉紅、耳朵發紅、手抖、小聲說謝謝，都是 AI 容易做的微表情，不用大量台詞。
- **不靠可讀文字**：手機記事本的字、投票題都標「後製字卡」，畫面本身不需要 AI 生字。
- **不碰地雷**：沒有打鬥、沒有原住民或新住民身分的笑點，沒有家裡職業或經濟的玩笑，沒有無照騎車。

# 自評：最大的風險

阿蓮的「跟性別沒關係」如果寫得太像老師講道理，會把第 2 節拍變成說教，而且要特別注意她的原住民身分只是日常背景，不要讓她的「會修車」變成族群特質的誇大。
