# 寫手須知（每位寫手都會拿到這份，加上該集題目卡）

> 主編：Claude Opus（只評分、選案、寫意見，不動筆寫劇情）。
> 這一輪只要**概念＋節拍大綱**，不要寫逐場劇本。

## 一、你的任務
讀完下方「系列聖經」與「題目卡」，**自己想一個故事**，交一份發想（格式見第四節）。
- 題目卡只給能力目標與議題，**沒有情節線索是故意的**；請自己決定地點、道具、事件。
- 題目卡列在「避開」的題材，一律不要用。
- 全文使用**繁體中文（台灣用語）**；角色名字一律用中文（大頭、阿蓮、輝仔、老蔡），**不准英文或拼音**。
- 不要加前言或結語，直接從「# 概念名稱」開始。

## 二、系列聖經（跨集固定）

### 影集背景
- 屏東縣鄉間公立高中，**原住民重點學校**（排灣族、魯凱族學生多），也有不少**新住民第二代**（媽媽多來自越南）。
- 觀眾：15–18 歲高中生；看完要能在班上討論。
- 全劇 6 集、每月播 1 集；每集練一種「社會情緒能力」並搭一個生活議題。
- 風格：台味幽默、微誇張喜劇節奏（迷因感），輕鬆但不說教。
- 每集片尾：學生用手機寫一個詞投票，**最多人寫的詞會出現在下一集**（決定一個小細節，例如道具、台詞、稱呼）。

### 角色（4 位，個性跨集固定）
| 角色 | 設定 | 系列成長線（六集慢慢走完） |
|---|---|---|
| **大頭**（主角，男，膚色黝黑） | 衝動、重義氣、愛面子，脾氣來得快去得快；國語夾台語，口頭禪「免驚啦！」；家裡務農（作物未定，不要寫死具體作物）。 | 從「先衝再說」學會「先停一下」 |
| **阿蓮**（女） | 原住民（族別、族名未定，劇中只叫阿蓮，**不要寫族名、服飾、祭典**）。冷靜、話不多、手很巧；家裡開機車行，從小會修車；討厭「女生就該怎樣」。原住民身分是她的日常背景，**不是笑點來源**。 | 從「自己默默做好」到「也開口說出感受」 |
| **輝仔**（男） | 新住民第二代，媽媽來自越南，會中文和越南語。話少心細、觀察力強、內心戲多、愛講冷笑話；有自信，煩惱是想太多、怕出糗。**不是可憐角色**。 | 從「等別人先開口」到「自己先說出想法」 |
| **老蔡**（導師兼體育老師） | 國台語夾雜、直白溫暖；藍白拖、隨身小音響。不講大道理，只用問句或一個動作點到痛處，**答案由學生自己說出來**。 | 固定 |

- 角色的專長、家庭背景**不必每集都用上**；不要讓角色只靠專長解決問題。
- 除了以上 4 位，每集最多再加 1 位有台詞的配角（例如同學、家長），其他人只能是無台詞的背景。

### 第 1 集已定稿（兩個版本，供你了解角色，**不要重複這些題材**）
- 版本甲〈黃線〉：大頭在學弟妹面前把外套袖子扯破、被笑，藏進器材室；隔天外套被人用歪歪的黃線補好，他一路追查，發現縫的是老蔡。老蔡問「你剛剛講幾遍不在乎？」，大頭自己說出「我不是氣，是丟臉」。
- 版本乙〈一針見血〉：班會課每人縫一塊布章，大頭吼「這是女生做的啦」掩飾自己不會；老蔡問「吼完有比較不丟臉嗎」，大頭說出「丟臉」；放學後發現大家都留下來偷偷練。
- 兩版共同：大頭在第 1 集已經學會**叫出自己的情緒名字**（丟臉）。第 2 集以後要往前走，不要再演「發現自己其實是丟臉」。
- 第 1 集已用過：針線、縫補、外套、布章、器材室、找犯人推理。**之後各集不要再用。**

### 硬規格
- 片長約 **3 分鐘**（170–190 秒），16:9 橫式。
- 畫面由 AI 生成，所以：
  - 不寫打鬥、追逐、快速動作、劇烈鏡頭運動
  - **同一時間只有一個人說話**
  - 場景 **最多 3 個**；有台詞的角色 **最多 5 個**（含 4 位主角）
  - 不靠畫面裡的可讀文字傳達資訊（要字卡的話標「後製字卡」）
  - 關鍵線索、道具要**夠大、夠好認**，不要靠失焦的小細節
- 語速以每秒約 5.5 字估算；台詞約占片長 25–40%。
- 對白以國語為主，自然夾台語詞；台語詞用常見寫法。

### 地雷清單（違反任一條就不及格）
- 原住民：不用唱歌跳舞、運動好、力氣大、喝酒、樂天、加分當笑點；不寫族名、服飾、祭典
- 新住民：不模仿口音、不用「外配」、不只用食物代表文化
- 不拿家裡職業、經濟狀況開玩笑
- 不用打頭、威脅、受傷住院、懷孕、身材、身障當笑點
- 「男人婆」「娘」這類稱呼若出現，劇情必須有清楚的回應，不能只當笑點
- 不放真實歌名、品牌、名人、真實地名商家
- 不出現無照騎車、不戴安全帽、翹課、說謊等被劇情默許的行為；若出現，劇中要有回應
- 不寫說教句（「以後要記得…」「這告訴我們…」）；情緒要由角色自己**說出那個情緒的詞**，老師最多 3 句問句

## 三、節拍原則
- 結構：**鉤子（前 10 秒）→ 推進（主角至少換一次策略）→ 反轉或揭曉 → 收尾**。
- 先想好結尾畫面，再倒推前面。
- 情緒要有**看得見的身體信號**（例如手抖→手穩、耳朵紅），開場和結尾對照。
- 本集的情緒能力要「演出來」：觀眾看到角色做了不同的選擇，而不是聽到有人講道理。

## 四、交件格式（照順序、用這些標題）
```
# 概念名稱
# 一句話故事
# 開場鉤子（前 10 秒）
# 主角目標與主要阻礙
# 核心故事引擎（為什麼會一直想看下去）
# 主要驚喜或情緒回報
# 結尾畫面
# 節拍大綱（6–8 個節拍，標秒數，總長約 180 秒）
| 秒數 | 場景 | 發生什麼 | 不可逆的新資訊／選擇 |
# 上一集投票詞放哪裡
# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
# 伏筆與回收
# 適合 AI 影片生成的理由（場景數、有台詞角色數）
# 自評：最大的風險
```
全文約 1,500–2,500 字。
