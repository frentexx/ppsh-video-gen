# 方向 A：先別替我猜

# 一句話故事
拍班級介紹短片時，輝仔被同學一句刻板印象的玩笑推到鏡頭外，大頭明明可以裝沒事，卻選擇喊停，讓輝仔自己決定要怎麼被介紹。

# 開場鉤子（前 10 秒）
手機已架好，四人準備拍班級短片。小芸對輝仔笑著說：「（你媽媽是越南人，你一定很會講越南話吧？）」此句需原住民教師／熟悉新住民家庭老師確認。輝仔原本要按錄影，手指停在半空；大頭跟著乾笑，阿蓮低頭看見輝仔把手慢慢縮回去。

# 主角目標與主要阻礙
大頭的目標是把短片一次拍完，不在大家面前顯得掃興；主要阻礙是他看見輝仔被一句「好像沒惡意」的話定義，卻不知道怎麼開口。若喊停，大家會嫌他太敏感，短片也可能來不及交。

輝仔想完成自己的介紹，但不想被安排成「代表某種文化的人」。阿蓮察覺不對，卻習慣先把場面處理好，不一定會說出自己的感受。小芸不是壞人，只是把好奇直接丟給別人，還沒意識到那句話已經讓人不舒服。

# 核心故事引擎（為什麼會一直想看下去）
短片每次重拍，大頭都必須在「趕快完成」和「替輝仔保留選擇」之間做決定。第一次他選擇沉默，第二次他想用改台詞帶過，最後才真正喊停，承擔被大家嫌麻煩的代價。

觀眾會一直等：輝仔最後會不會留下來？大頭會不會真的站出來？小芸能不能從「我只是開玩笑」走到聽懂對方的界線？

# 主要驚喜或情緒回報
大頭不是用更大的笑話反擊，也不是要求輝仔證明自己會不會某種語言，而是把手機交給輝仔：「你想怎麼介紹，就怎麼拍。」

輝仔沒有立刻講很多，只說：「我不要被猜完。」這句話讓阿蓮也開口：「我剛剛也不舒服，只是不知道要不要講。」兩人都不是被拯救，而是自己說出界線。

# 結尾畫面
手機重新開始錄影。輝仔站在畫面中間，沒有照原本分配好的台詞，而是說：「我是輝仔，怎麼介紹我，先問我。」

鏡頭外的大頭沒有搶話，只把手機穩穩拿好。小芸站在旁邊，對輝仔說：「那我重來，先問你。」後製字卡浮出：「先問，再說。」四人看著手機，沒有人笑場。

# 上一集投票詞放哪裡
放在第 5 拍的手機畫面，作為後製字卡「［第3集投票詞］」，再由大頭看著手機說：「這個詞，現在剛好。」它不依賴特定字義；換成任何合理詞語，都能成為他按下停止前的一個心理提示。畫面不需要生成可讀文字，後製再補上即可。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
題目：**「要跟家人談一件麻煩事前，你最想先做什麼？」**

預期詞：聽、問、說、等、一起。

第 5 集主題是「跟家人好好說 × 氣候變遷」，最高票可成為角色第一次開口前的動作，例如先聽家人說完、先問家人的擔心，或先說自己的感受。題目不要求填任何族群形容詞，只能填動作或一般感受詞。

若出現不雅字詞，後製只統計合乎題意的動作詞；不在畫面展示原字，改以「未收錄」統一處理。

# 伏筆與回收
- 開場大頭跟著乾笑，結尾他安靜拿穩手機，完成從附和到站出來的身體對照。
- 輝仔開場把手縮回去，結尾主動拿回手機，完成從等待別人處理到自己說明界線。
- 阿蓮開場只觀察，結尾說出「我也不喜歡」，推進她從默默做好到表達感受。
- 小芸一開始拿著固定台詞，結尾把台詞放下，表示她不再替別人安排身分。
- 「先問，再說」可作為下一集角色面對家人時的行動節奏。

# 自評：最大的風險
刻板印象台詞即使只出現一次，仍可能讓觀眾感到被模仿或被代表。必須由原住民教師／熟悉新住民家庭老師確認語境與措辭，並確保鏡頭停在輝仔與旁人的反應，不給玩笑句笑點或重複曝光。小芸的回應也不能只停在「我沒有惡意」，要明確改成先詢問輝仔。

# 方向 B：每個人自己的那一句

# 一句話故事
四人拍一支「怎麼跟同學相處」的班級短片，大家為了省時間想把每個人的回答剪成同一句話，大頭最後選擇保留每個人的不同說法，讓阿蓮第一次說出她不想被做成一致的樣子。

# 開場鉤子（前 10 秒）
手機正在錄影，大頭對鏡頭喊：「我們班，全部都一樣！」阿蓮立刻伸手按停。她手上拿著四張大色卡，原本準備一人一張，卻被大頭收成一疊。輝仔看著那疊卡片，冷冷說：「那幹嘛還要拍四個人？」

# 主角目標與主要阻礙
大頭想做出整齊、好笑、能準時交出去的短片；阻礙是四個人對「怎麼跟自己相處」有不同界線和習慣，而最省事的做法正是把差異剪掉。

阿蓮想把自己準備好的內容留下來，但一開始只默默把色卡重新排好，沒有說出不滿。輝仔則擔心自己的回答太特別，選擇不搶著發言。小芸認為大家講一樣比較清楚，並非有惡意。

# 核心故事引擎（為什麼會一直想看下去）
每次錄影都會遇到一個「為了整齊，要不要刪掉差異」的選擇。大頭先刪短句，再把四個人的回答改成同一種語氣，最後必須決定：是交一支漂亮但不像任何人的影片，還是留下不整齊、卻真的屬於四個人的版本。

觀眾會等阿蓮何時會開口，也會看大頭能不能理解「做對的選擇」有時就是放棄自己最想要的整齊感。

# 主要驚喜或情緒回報
阿蓮的色卡不是四個人的統一標語，而是四種不同的「相處前先問的事」：有人需要先聽完，有人需要先確認，有人需要一點時間，有人希望直接說清楚。這些不是族群標籤，而是每個人自己選的相處方式。

當大頭問阿蓮「妳想留下哪一句？」阿蓮沒有再用點頭帶過，而是說：「我不想再被剪成跟大家一樣。」這句話成為全片最安靜、也最直接的轉折。

# 結尾畫面
四張色卡被放在手機前方，沒有排成整齊直線，而是各自留著一點距離。四人依序說自己的句子，語氣和停頓都不一樣。最後大頭看著鏡頭說：「我們不是全部一樣，是都可以在這裡。」

阿蓮看向手機，確認自己的那張卡留在畫面裡，肩膀放鬆。後製字卡浮出：「留自己的那一句。」
