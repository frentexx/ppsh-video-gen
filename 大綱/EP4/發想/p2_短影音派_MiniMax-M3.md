# 方向 A（碰）

# 概念名稱
「欸，輝仔——」

# 一句話故事
大頭接下班刊主編，想替同學「開口說話」，卻在大家裝沒事的時候先看見那句話——他第一次在猶豫之後，選擇停下來，然後開口。

# 開場鉤子（前 10 秒）
教室外走廊，課間。大頭拿著手機對鏡頭自嗨：「這期班刊主題——認識我們班上的人。交給我，免驚啦！」牆上展開他畫的三格分鏡圖，立可貼還在冒頭。

# 主角目標與主要阻礙
大頭目標：用他的方式做出「大家都看得懂」的班刊。
阻礙：他以為「大家都要開口講」，可是有人不願被推著講、又不好意思說；更難的是他自己——聽到一句不對勁的話，他跟著笑了。

# 核心故事引擎
觀眾想看：大頭到底會不會站出來？他怎麼開口？說出來會不會反而把事情弄得更尷尬？

# 主要驚喜或情緒回報
大頭沒有大聲疾呼，也沒有道歉秀。他走到那位配角（同學）面前，平靜一句：「下次先問他，不要直接幫他決定。」沒有台詞大道理，卻讓現場安靜了半拍。

# 結尾畫面
放學，兩人並肩走出校門。輝仔：「欸，你今天怎麼那麼晚走？」大頭手插口袋、腳步慢一拍：「沒啦，一點事，免驚啦。」兩人笑一下。

大頭鉛筆盒側邊貼著一張小貼紙，字寫得不小——也就是第 3 集最高票的詞。第 45 秒（配角丟出那句話之前）快速帶過一次：詞是什麼不重要，這張小貼紙是大頭對自己「是不是一直這樣」的小提醒。換成任何合理的單字（停一下、換位、體諒、安靜……）都讀得通。

# 片尾投票題
題目：「聽到一句話心裡覺得『嗯？』的時候，你第一個反應是什麼？」（用「嗯？」避免預設情緒）
預期詞：猶豫、卡住、想幫、悶、安靜、想走開、停一下。
下一集（第 5 集，家人 × 氣候變遷）怎麼用：大頭想跟阿嬤提起換節能燈泡、想跟媽媽聊颱風前的打包，但他會卡住——本集票選的那個詞會化為道具（一張便條）或一句口頭禪。無論票選哪個詞都接得上。

# 伏筆與回收
- 大頭自畫的三格分鏡圖，開場建立、結尾未拆，下集他還在籌班刊——可在 EP5 接續。
- 阿蓮的那句低聲問話，是她「從默默做好到開口說出感受」的一小步，下集可再走一步。
- 老蔡只丟一個問、不給結論的節奏，在 EP5、EP6 重複出現。

# 自評：最大的風險
配角那句話的尺度。寫太重會像在示範歧視；寫太輕觀眾感受不到大頭的猶豫。定稿前一定要請熟悉新住民家庭／原住民背景的老師把關那句話；另外，大頭走向配角（同學）那場不能拍成「學長教訓學弟」，要保持語氣平、無特效。

# 方向 B（不碰）

# 概念名稱
「我自己來」

# 一句話故事
大頭想用「公平」的方法讓每個人都介紹自己的家，他真正做「對的決定」的那一刻，是聽見每個人想用自己方式說的那一秒。

# 開場鉤子（前 10 秒）
教室，老蔡剛在黑板寫「本期班刊主題：我的家」。大頭馬上舉手：「交給我。」轉過頭面對同學，自信笑一下。

# 主角目標與主要阻礙
大頭目標：用統一版型讓「每個人」都能交一份「介紹我家」的稿件。
阻礙：他的預設是「大家都要寫字、都要說出來」——可是阿蓮習慣用圖，輝仔還在找怎麼用一句話講家裡那些東西，另一位配角（同學）連「該不該交」都不確定。大頭沒惡意，但他預設得太快。

# 核心故事引擎
觀眾想看：大頭什麼時候會聽見「別人不想照我的方式」？他修正版型的那一刻，會讓誰願意交稿？

# 主要驚費或情緒回報
不是大頭突然變得很會「理解別人」，而是他笨拙地把自己畫好的框撕掉三條立可貼，換上一張新便條：「用你自己的方式，說一點點也行。」被看見的人是阿蓮——她終於願意交稿，而且是用自己的方式。

# 結尾畫面
班刊印出來攤在桌上，三頁並排：大頭那一頁是速寫加兩行字、輝仔那一頁是一張照片加他自己的一句話、阿蓮那一頁是她交的那張素描。大頭用手指輕輕翻過那三頁，嘴角彎一下。
