# 方向 A（碰）

## 概念名稱：稿紙在抖

# 一句話故事
朗讀比賽選代表時，同學阿翔脫口一句「輝仔，你中文怎麼講這麼好」，全班笑了；大頭停了三秒，沒有開砲，發現阿翔手裡那疊在抖的稿紙，才是這句話真正的來處，然後選擇在全班面前把話接過去，並付出被冷場的代價。

# 開場鉤子（前 10 秒）
特寫：一疊厚厚的、橘色封面的朗讀稿，被一雙手捏到皺，微微發抖。鏡頭拉開：是阿翔，他坐在教室角落，眼睛一直盯著老蔡手裡的點名簿。

# 主角目標與主要阻礙
大頭的目標：快點選完代表，趕去午休（輕目標）。阻礙：阿翔說出一句帶刻板印象的話，全班笑，輝仔笑著回應，但耳朵紅了；大頭的老毛病（衝動、愛面子）想當場開砲，卻也怕讓氣氛變糟。

# 核心故事引擎
觀眾先看到「怕朗讀的阿翔」，再看到他說出刺人的話，會期待大頭一拳打過去；但本集反轉：刺的人自己也是被嚇到的人。懸念是「那句話之後，誰先說話」。

# 主要驚喜或情緒回報
- 揭曉：阿翔把老蔡點名的矛頭，轉到輝仔身上，是想「躲過下一個被點」。（回看開頭的發抖稿紙就成立。）
- 回報：阿蓮第一次主動說出感受；輝仔用自己的方式回應，不是為了「證明什麼」；阿翔沒有被審判，但不能沒事。

# 結尾畫面
輝仔和阿翔並排坐著，手上各一份橘色稿紙，互相交換一頁。阿翔手穩了，耳朵不紅了。大頭在後排伸懶腰，手垂在椅背外，是放鬆的。

# 上一集投票詞放哪裡
75–105 秒：大頭想罵人的那一刻，心裡閃過第 3 集最高票的詞（作為「暗號／口令」，任何名詞都可以，例如「鬧鐘」「謝謝」）。他用這個詞止住，變成班上默契；詞不需要被念出來，也可以出現在他舉起的手勢或黑板小圖。

# 自評：最大的風險

# 方向 B（不碰）

## 概念名稱：四點五十分

# 一句話故事
同學阿凱每天一到下午四點五十分就像逃跑一樣衝出教室，全班拿他當笑話；班級合照約在放學後，大頭選擇在大家都笑的時候不笑，而且為了讓阿凱能入鏡，改掉大家都愛的夕陽時段。

# 開場鉤子（前 10 秒）
教室牆上一個巨大的黃色圓鐘，秒針滴答。四點五十，阿凱的書包已經背好，椅子推進去，眼睛盯著鐘。鐘聲響，他像被按下開關，快步（不是奔跑，用快走）出教室。同學們互相使眼色、模仿他的動作，笑成一團。

# 主角目標與主要阻礙
目標：班級合照要拍到「夕陽金色光」那一刻（約五點十分），全班都要入鏡。阻礙：阿凱一定會在四點五十離開，大家不懂他為什麼。

# 核心故事引擎
觀眾和大頭一起想：「他在躲什麼？」大頭本來也在笑，輪到他必須決定：繼續笑、還是停下來問。

# 主要驚喜或情緒回報
反轉：阿凱不是怕大家，而是家裡規定「五點前一定要到家」，他怕說出口像「媽寶」。他的急，是因為一件很平常的事（家規）。回報是大頭不笑、改時間，阿凱終於可以站在鏡頭裡。

# 結尾畫面
下午四點半的光，教室外走廊，全班站成一排，阿凱站在最中間。大頭按下自拍架的快門，時間顯示尚早，大家的臉有點不夠金，但笑得很自然。
