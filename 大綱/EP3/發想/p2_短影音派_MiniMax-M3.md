# 概念名稱：水壺底的事

# 一句話故事
班際盃備戰倒數三天，大頭帶的球隊頻頻出包的是「水壺管理員」輝仔；大頭從想開罵到踩煞車，最後在器材牆邊，主動開口問出輝仔每晚只睡三小時的原因。

# 開場鉤子（前 10 秒）
大頭手機自拍入鏡，黑臉湊近：「免驚啦，三天後穩贏的啦！」鏡頭瞬間拉遠——同一秒，後方塑膠水桶被踢翻，水花潑地。大頭嘴硬補一聲：「……免驚。」字幕卡：班際盃倒數三天。

# 主角目標與主要阻礙
目標：大頭想帶隊奪冠，證明自己「真的轉大人了」（接 EP2 學到的「先停一下」）。
阻礙：輝仔送水遲到、毛巾數錯、每件事都先問「這樣對不對？」，節奏全亂；隊友不耐；大頭好幾次差點舊脾氣爆發。

# 核心故事引擎
大頭每次想開罵，腦中自動浮現上一集自己踩煞車的畫面。問題是，這次煞車還撐得住嗎？他會撐幾次？最後一次撐不住會發生什麼事？

# 主要驚喜或情緒回報
輝仔不是笨，也不是怕事，是每天凌晨跟媽媽做網拍家庭代工（摺衣服、貼標、裝袋），只睡三小時。**大頭沒說「加油」，而是主動重新分工**；輝仔也第一次主動講出感受：「我不是不想做，是我會睡過頭。」——這一步讓他的成長線從「等別人問」推進到「自己先開口」。

# 結尾畫面
練習賽結束（用記分板顯示結果，不需要演打球過程）。走廊上，大頭把水壺遞給輝仔，主動開口：「回家那包貨，明天我來摺。」輝仔愣半秒，接過水壺，難得主動補一句：「……下次，讓我也上場。」大頭挑眉：「先睡飽再講。」

# 上一集投票詞插槽
本集預留「道具詞插槽」：休息區小黑板上，輝仔手寫的一句話。我先以示範詞「乖乖」填入：「乖乖收毛巾」，語意自然、字卡清楚可讀。換成任何合理名詞（例：「冷氣」「黑板」「布丁」「手機」），都能改成「OO收毛巾」「OO別忘了」之類，3 秒內讀懂、不破壞節奏。黑板只在 75–115 秒那顆鏡頭出現一次，不佔主畫面。

# 片尾投票題
**題目**：「最近一次幫家裡做的代工／家事，你會怎麼稱呼它？」
**預期會出現的詞**：「摺衣服」「貼標」「顧店」「洗碗」「載貨」「照顧」。
**下一集怎麼用**：最高票詞會出現在 EP4 開頭，教室佈告欄一張手寫便利貼上（例：「我們都嘛不一樣」這句底下，貼著前晚的便利貼「摺衣服」），成為 EP4「多元文化」議題的班級氛圍鋪墊——讓老師可以順勢問出「每個家本來就不一樣」。
**不雅字詞處理**：後製字卡只顯示前 30 字；輸入不雅詞自動變成「__ _ _」馬賽克字卡，不影響投票機制。

# 自評：最大的風險
「每晚幫媽媽做家庭代工」若處理不慎，會被讀成新住民家庭苦情刻板印象。具體避險：
1. 台詞裡讓輝仔自己補一句「是我自己要幫的，我媽叫我去睡」——把主詞還給他。
2. 鏡頭不拍家裡、不拍媽媽，只讓「手上黑眼圈」與「補貨到三點」這兩個身體信號說話。
3. 大頭的回應不是同情，是「明天換我摺」——行動接住，非憐憫。
4. 食物、春捲、家鄉元素**完全不入鏡**，避免落入「食物代表文化」。
