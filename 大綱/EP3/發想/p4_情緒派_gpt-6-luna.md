# 慢半拍也算一拍

# 一句話故事
大頭帶著阿蓮、輝仔和老蔡拍一段課間伸展影片，輝仔一直慢半拍，大頭差點把他當成拖累；但輝仔主動說出自己為了跟上大家熬夜練習，四人改成讓每個人都能完成的節奏，最後由最怕出糗的輝仔帶大家做完。

# 開場鉤子（前 10 秒）
空教室前方，手機已架好，四人穿著男生淺藍、女生淺粉紅的運動服。

大頭面對鏡頭抬手：「三、二——」

輝仔的手停在半空，慢了整整一拍。大頭的嘴角抽動，拳頭握緊；輝仔立刻把手放下，像是想把自己藏到最後面。

老蔡按掉錄影：「卡。」

# 主角目標與主要阻礙
大頭的目標，是在體育課結束前拍出一段整齊、安靜、大家都能做完的伸展影片，交給老蔡當作班上的健康活動示範。

主要阻礙是輝仔總在換動作時慢半拍，讓大頭覺得整段影片會被他拖垮。輝仔不是不會做，而是太害怕出錯，反覆在心裡對拍子，反而每次都慢一步。

大頭本集要把「先停一下」用在別人拖累自己的時候：不是壓住脾氣後繼續逼，而是停下來確認對方卡在哪裡。輝仔則要從等別人發現，走到自己先說出真正的狀態。

# 核心故事引擎（為什麼會一直想看下去）
每次重拍，輝仔都只差一個小地方，讓大頭以為「再來一次就會好」。但越重拍，輝仔的動作越僵，從抬手、側彎到坐下，都像隔著一層看不見的玻璃。

觀眾會一直想看：大頭什麼時候會爆？輝仔到底是跟不上，還是有別的原因？四人最後要選擇追求畫面上的完美，還是一起把節奏改成真的做得到？

運動不靠快速動作呈現，而是用固定位置、慢速伸展、手勢與呼吸節拍，讓「團隊是否接住一個人」成為畫面焦點。

# 主要驚喜或情緒回報
輝仔不是整晚滑手機，也不是偷懶。他前一晚怕自己拖累大家，對著手機錄下的語音反覆練習，練到很晚，甚至把四人的動作順序畫成大格子，想記得更牢，結果睡眠不足，腦袋反而慢半拍。

他不是等人安慰，而是在大頭又要喊重來時，自己先說：「我不是不想跟，我昨晚練太久，現在腦袋一直慢一格。」

大頭停住，沒有立刻回「那你早講」。他改問：「你現在做哪一段最穩？」

輝仔指出自己最穩的是數拍和提醒換動作。團隊於是讓他當口令，不再要求他硬跟前三人的同步動作。這不是把輝仔排除在畫面外，而是讓他的細心成為團隊需要的部分。

# 結尾畫面
最後一次拍攝時，四人站成一排，動作簡單而一致。鏡頭外的輝仔先數：「一、二、三、四，換。」

大頭原本習慣搶在口令前動作，這次停半拍，等輝仔的聲音落下才抬手。四人慢慢完成側彎，再把手放回身側。

拍攝結束，輝仔看著手機畫面，小聲問：「這次可以嗎？」

大頭把手機轉向他：「不是可以，是你帶的。」

輝仔耳朵微紅，但沒有躲開。他把手掌攤開，接過手機。

畫面停在四人伸展後的姿勢：大頭的拳頭已經鬆開，輝仔站在隊伍中間，手裡握著大紙板上的投票詞。

# 上一集投票詞放哪裡
第 2 集最高票的名詞或短詞，放在本集第 116–142 秒的「大紙板暗號」上。

老蔡拿出一塊大紙板，說：「上一班留下的詞，今天拿來當換動作的暗號。」紙板上的詞由後製字卡替換，輝仔每次要提醒大家換動作時，先喊那個詞，再數「一、二、三、四」。

例如最高票若是「穩住」，輝仔就喊：「穩住，換。」若是「勇氣」「清醒」「不要急」等任何合理名詞或短詞，也都能成為四人的節奏暗號，不影響情節與動作。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
題目：遇到不同的聲音時，你覺得第一步該做什麼？請用一個詞回答。

預期最多人寫的詞：「先問」。

下一集用法：第 4 集面對多元文化議題時，主角看到同一件事有不同做法，最先出現的動作不是猜測或嘲笑，而是有人說：「先問。」這個詞也可以成為下一集的行動暗號，讓角色在做選擇前先向對方確認。

不雅字詞處理：後製只統計符合題意的詞；不雅、攻擊個人或族群的字詞不顯示、不列入票數，也不拿來做笑點。畫面可用「未收錄」取代，不呈現原字。

# 伏筆與回收
- 開場輝仔每次動作前都會先看大頭的肩膀，回收時改成他自己喊拍子，顯示他不再被動等別人帶。
- 大頭開場握拳、差點把輝仔排除；中段問「你哪段最穩」；結尾把手機交給輝仔，完成從壓住脾氣到主動接住對方的轉折。
- 阿蓮一開始沒有替輝仔解釋，只用眼神確認他是否要自己說；後來她把大紙板交給輝仔，支持他的選擇，而不是代替他發言。
- 老蔡前段只問「今天要拍什麼？」和「如果有人跟不上，還算一起嗎？」最後不下結論，讓大頭和輝仔自己改變方法。
- 大紙板上的投票詞同時是上一集的回收，也是本集團隊重新找到節奏的具體道具。

最大的風險是「熬夜練習」若處理不好，可能變成鼓勵用過度努力換取團隊認可。劇情必須明確讓輝仔說出自己練太晚反而狀態變差，也讓團隊調整任務，而不是稱讚他熬夜。
