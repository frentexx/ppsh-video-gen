# 概念名稱
〈拖累〉

# 一句話故事
班上推行「每天一萬步」的團體挑戰，大頭當組長，他在班群公開點名小傑「拖累全班」，直到他發現小傑夜裡要陪奶奶，白天一趴下去就醒不過來。

# 開場鉤子（前 10 秒）
白板上的健走表格，每人一欄，小傑那一欄連續三天是 0。大頭拿著麥克筆，一邊寫一邊嘆氣，班群同時跳出他打的一行字：「小傑又是最後一名，是要拖到什麼時候？」

# 主角目標與主要阻礙
目標：讓全班在挑戰裡拿到第一，證明大頭這個組長有用。
阻礙：小傑不說原因，只說「我沒有時間」；大頭看不見的，是小傑的睡眠和家裡的狀況，而他很怕自己看起來像在護著小傑。

# 核心故事引擎（為什麼會一直想看下去）
每場戲都在問：小傑到底為什麼一直趴著？大頭什麼時候會發現自己錯了？觀眾會一直猜「是偷懶嗎」，然後被慢慢翻轉成「他其實很累」。

# 主要驚喜或情緒回報
班群裡的「拖累」兩個字，在第三分鐘會被小傑自己拿回來講：「我不是拖累，我是睡不著。」大頭的怒氣沒有被壓住，而是被換成一句「那我們改怎麼走」。

# 結尾畫面
操場邊的樹蔭，大頭和小傑慢慢走一圈，白板的表格背景是靜態的，隊名的那一格寫著［投票詞插槽］隊。鏡頭拉遠，兩人的影子很長，走得很慢。

# 上一集投票詞放哪裡
第 2 集最高票的詞會變成班級健走隊的隊名，寫在白板最上面一格，格式是「<詞>隊」。第 3 拍大頭唸隊名時，鏡頭停在白板上，讓觀眾看到這個詞。
- 若詞是「深呼吸」，隊名就是「深呼吸隊」。
- 若詞是「停」或「三秒」，隊名就是「停隊」或「三秒隊」，仍然念得通。
- 若詞是「冷靜」，隊名是「冷靜隊」，剛好對應大頭在第 2 集學到的停頓。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
題目：「你覺得一個團隊裡，最需要的是哪一種人？」
預期詞：耐心、體諒、認真、幽默、會聽、會等。
下一集用法：最多人寫的詞會寫在第 4 集班會的黑板標題上，作為班會主題的一個字，角色不必解釋。
不雅字詞：含罵人或貶低他人的詞不列入計票，只顯示「已過濾」。

# 伏筆與回收
- 小傑的「晚上會醒」在第 2 拍就用手勢帶過（他一直揉眼睛），第 4 拍才說出原因。
- 輝仔的冷笑話可以在第 3 拍出現一次，接著把他「想太多」的心內戲放在一個停頓裡。
- 白板的表格會在第 6 集再出現，格子裡的數字已經變了。
