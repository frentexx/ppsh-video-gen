# 紅貼紙

# 一句話故事
全班合力挑戰「連續五天睡飽」，貼紙牆上永遠只有阿傑一格是紅的，大頭氣到想當眾點名；他停下來才發現，全班最「拖累」大家的那一格，是唯一老實的一格，而他自己的綠貼紙是假的。

# 開場鉤子（前 10 秒）
教室後牆一張巨大海報，格子裡貼滿綠色圓貼紙，只有阿傑那一格是顯眼的紅色。大頭站在海報前，雙手叉腰，下巴抬高，鏡頭慢推到紅貼紙。旁白式一句：「五天全綠，午休多十分鐘。就差這一個。」

# 主角目標與主要阻礙
目標：讓全班貼滿綠貼紙（睡滿八小時），贏得「午休多十分鐘」。阻礙：阿傑每天早上都貼紅色，大頭認定他在拖大家後腿。

# 核心故事引擎（為什麼會一直想看下去）
「為什麼只有他是紅的？」大頭一路想找出原因並逼他改，觀眾也被吊著。每天早上海報都是同一個畫面，只有格子細微的變化，形成節奏與期待。

# 主要驚喜或情緒回報
反轉有兩層：
1. 阿傑的紅貼紙是因為他「老實」：他前一晚真的睡不著，所以誠實貼紅。
2. 當大頭想當眾說「你到底睡不睡啊」，他先停下，結果看到自己的綠貼紙：昨晚他看影片看到半夜，是假綠。他承認後，其他人也默默把貼紙撕下來換成紅色。海報變成一片紅，反而是全班第一次「誠實」。

# 結尾畫面
海報上紅色貼紙遍地，阿傑那一格旁邊多了一個小小的綠點（他自己貼的，第一個真正的綠）。大頭打哈欠，眼睛半閉，嘴角是笑的。老蔡的小音響關小聲，鏡頭停在海報。

# 上一集投票詞放哪裡
85–120 秒：大頭在黑板角落（或群組貼圖／口令）使用第 2 集最高票的詞，作為「十點放手機」的暗號。無論詞是「手機」「便當」「發呆」「快點」，都可以成為班上的暗號（詞當作名詞：「喂，XX 時間到」）。必須自然放入劇情，而非念出來交差。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
題目：「你覺得班上最『看不見』但很重要的一件事是什麼？寫一個詞。」預期：打掃、笑容、安靜、謝謝、鬧鐘。下一集：最高票詞可以作為第 4 集班級「默契」的小道具或稱呼。不雅字詞由老師後台過濾，不計入。

# 伏筆與回收
- 阿傑大紅鬧鐘（前三分之一）→ 揭曉他靠鬧鐘滴答聲入睡，且鬧鐘最終放到全班面前，不是被取笑的東西。
- 大頭自己的綠貼紙→ 他是否誠實就是反轉。
- 輝仔舉手又縮回→ 在 120–150 秒第一次先開口。
- 午休多十分鐘的獎勵→ 最終沒有贏，卻換到更重要的東西（誠實與接住）。

# 自評：最大的風險
「說謊」的處理：大頭貼假綠要有清楚的回應，我已安排他自己撕下；但「全班跟著撕」若太順，可能顯得太集體喊口號。也要小心阿傑不要被塑造成「睡不著的可憐角色」，可加入他同時有自己的幽默（鬧鐘自我解嘲）。另外第三場「放手機」可能有說教氣味，需要靠動作而非台詞。
