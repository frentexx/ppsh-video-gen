# 頭燈

# 一句話故事
大頭以為爸爸每次都用「沒空」躲掉他的家長日，氣到想大吼；他半夜醒來看見爸爸戴著頭燈出門，才知道天氣太熱，爸爸現在只能在天亮前下田、白天補眠，而爸爸不說，是怕兒子覺得他在喊累。

# 開場鉤子（前 10 秒）
黑畫面。鬧鐘聲。一道很亮的白光從門縫掃過，照在牆上的家長日通知單（一張大紙，用顏色與形狀表現，不靠字）。鏡頭轉：大頭睜眼看著那道光離開，嘴角往下撇。

# 主角目標與主要阻礙
目標：讓爸爸來參加家長日（下午）。阻礙：爸爸每次都說「下午沒空」，大頭認定他不在乎，一說就想吵。

# 核心故事引擎
一開始觀眾也會誤會爸爸，覺得他不夠關心；每一次爸爸說「沒空」，都有一個畫面碎片（頭燈、斗笠蓋臉睡午覺、濕透的長靴）。這些碎片拼起來，才是真相。

# 主要驚喜或情緒回報
反轉：爸爸不是不想來，而是氣候越來越熱，白天田裡待不住，他改成凌晨三點下田，下午一定要睡才撐得住；他怕大頭知道他累，會擔心、會自責。回報是大頭換了一種說法：從「你都不來」到「我有點失望，也擔心你」。爸爸也說出「我怕你覺得爸爸老了」。

# 結尾畫面
清晨六點，田邊，爸爸與大頭並肩坐在小板凳上，各捧一杯熱茶，頭燈放在兩人中間，還亮著，光變淡了。大頭手心攤開（開場是握拳）。

# 上一集投票詞放哪裡
85–115 秒大頭寫在便條上的詞，在 150–170 秒由爸爸念出來。這個詞可以是任何名詞或短詞（如「謝謝」「辛苦」「擔心」），都能變成一張遞給爸爸的小紙條或一句暗號。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
題目：「這學期你自己最大的改變，用一個詞來說？」預期：停、說、慢、笑、勇敢。下一集（大結局）：最高票詞可作為四人回顧時的一個口頭禪或小道具。不雅字詞由老師後台過濾，不計入。

# 伏筆與回收
- 頭燈（開場）→ 結尾放在兩人中間。
- 爸爸午睡蓋斗笠（第 15–50 秒穿插）→ 回收為「白天太熱」。
- 沾泥長靴（50–85 秒）→ 讓大頭看見而不再大吼。
- 通知單→ 結尾以影片參加。

場景 3 個（臥室、飯桌、田邊）；有台詞角色 3 位（大頭、爸爸，輝仔以視訊，僅一句）；動作少，頭燈、斗笠、長靴為大型物件，無災害畫面。

# 自評：最大的風險
爸爸的「怕你覺得我老了」可能太直白、像說教；氣候變遷只出現在「天氣太熱」一句，可能過輕；另要確保大頭「凌晨出門」有交代（爸爸在田邊就知道，並非離家），否則會被視為默許深夜外出。
