# 先問再說

# 一句話故事
極端高溫讓田裡的用水時間被迫改變，大頭因為阿爸不肯讓他碰水閥而覺得不被信任，差點用老方法頂回去；但他先停下，改問阿爸真正擔心什麼，才發現阿爸不是只怕作物缺水，更怕大頭為了證明自己而把身體撐壞。

# 開場鉤子（前 10 秒）
大頭滿頭汗地打開家中水龍頭，水只「咳」一聲就停了。他抬頭看牆上的大型溫度計，紅線已經頂到最上方。阿爸立刻把一個大水桶抱走，擋在水龍頭前。

大頭：「洗臉也要排隊喔？」  
阿爸：「這桶，留到晚上。」

大頭的手停在半空，耳朵慢慢紅起來。

# 主角目標與主要阻礙
大頭的目標，是說服阿爸讓他一起處理田裡的灌溉安排，證明自己不是只會衝動添麻煩，也希望家裡不要把高溫和缺水當成「撐一下就過去」。

主要阻礙是阿爸的話很短，只說「照原本的來」「你先不要碰」，沒有說出真正的擔心。大頭一開始把這些話聽成「你不夠可靠」，越聽越想頂回去。阿爸也不是反對改變，而是擔心大頭為了幫忙，在最熱的時段硬撐，最後連學校和身體都顧不好。

# 核心故事引擎（為什麼會一直想看下去）
一個大型水桶和一支水閥，成為父子之間沒說出口的角力。大頭每次想證明自己，就要不要伸手碰水閥；阿爸每次阻止他，就讓誤會更深。

故事不靠災情升高，而是讓兩人面對同一個問題：天氣變了，家裡原本的做法還能不能照用？大頭必須在「立刻證明自己」和「先問清楚」之間做選擇。觀眾會一直想知道，他最後是搶著做，還是第一次把真正想說的話講給家人聽。

# 主要驚喜或情緒回報
大頭原本以為阿爸只在乎田裡的作物，甚至脫口說：「你顧水比顧我還認真。」阿爸沒有回罵，只把水桶上的手放鬆，說自己年輕時也曾在高溫下硬做，後來才知道「撐住」不等於「沒事」。

阿爸真正擔心的不是大頭把水閥弄錯，而是大頭一被質疑，就會用更用力的方式證明自己。大頭第一次沒有急著喊「免驚啦」，而是主動問：「你是怕我弄錯，還是怕我逞強？」阿爸終於回答：「兩個都有。」

# 結尾畫面
傍晚，兩人站在家門口的陰影裡。大型水桶旁放著一個小鬧鐘，水閥上掛著一條醒目的紅色布帶，代表「先確認時間」。大頭沒有直接打開水閥，而是先拿手機對阿爸說：

大頭：「現在可以嗎？我做二十分鐘，時間到就停。你如果擔心，直接講。」

阿爸點頭，接過手機替他設定計時。水聲響起，大頭的手沒有抖，阿爸也沒有把水閥搶回去。兩人一起看著水流，沒有誰站在誰的對面。

後製字卡：「下一集，最多人投的詞是——＿＿。」

# 上一集投票詞放哪裡
放在第 5 個節拍，以老蔡傳來的手機語音通知和後製字卡出現。老蔡只說：「第4集最多人投的詞，是＿＿。聽到這個詞，你先不要急著回。」接著大頭真的停三秒，讓投票詞成為他換策略的可見開關。

詞語不限定內容，換成「勇敢」「冷靜」「相信」「停一下」「聽」等合理詞都能成立：它不直接改變劇情，只提醒大頭這一刻要先做出不同選擇。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
- 題目：如果把大頭這次面對家人的改變寫成一個詞，你會投什麼？
- 預期會出現的詞：先說、聽、理解、穩、勇敢、改變。
- 下一集用法：第6集開場，四位主角在準備成果展時，手機跳出最高票詞；大家用這個詞替自己的成長取一個暫時稱呼，並在最後各自做出一個「先說出來」或「主動伸手」的選擇。任何上述詞都能放進對話或後製字卡，不會綁死劇情。
- 不雅字詞處理：投票畫面不呈現原字，統一以「＿＿」或「未入選」顯示；角色不朗讀，只保留合宜詞彙進入第6集。

# 伏筆與回收
- 開場水龍頭只發出空響，回收時水聲重新響起，對照家裡從緊繃到能共同決定。
- 大頭耳朵泛紅、手停在半空，是他情緒上來的身體信號；結尾他的手穩住，代表他沒有用衝動證明自己。
- 阿爸反覆說「留到晚上」「先不要碰」，前面像命令，後面才揭露其實是在保護大頭，也在面對氣候變化下的不安。
- 大頭原本說「免驚啦」的習慣本集不當口號使用；他最後改成「你如果擔心，直接講」，把安撫別人的話換成可溝通的約定。
- 手機計時器與水閥紅色布帶，讓「先說、可停止」成為第6集可以帶走的小道具語言。
