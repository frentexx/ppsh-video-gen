# 概念名稱
遮日頭

# 一句話故事
高溫熱浪讓大頭怕家裡的田撐不住，急著叫爸爸架遮陽網，父子吵到田邊；直到大頭把「我不是要教你，我是怕你一個人倒下去」說出口，爸爸才說出自己真正怕的是大頭受傷。

# 開場鉤子（前 10 秒）
教室裡熱得像蒸籠，輝仔拿課本搧風：「這種天氣，田會先中暑吧？」大頭低頭看手機裡的高溫警報，校外日頭白花花，他突然站起來：「免驚啦，我叫我爸架網。」

# 主角目標與主要阻礙
大頭想讓爸爸同意在田裡架遮陽網，不要一個人硬撐。阻礙是爸爸把兒子的急，解讀成「你嫌我不會顧田」；大頭越急越大聲，話到嘴邊都變成命令。

# 核心故事引擎
父子兩人都把「擔心」說成「指責」，等著看誰先停下來換一句話。大頭已經把遮陽網扛到田邊，梯子也架好了，衝突一碰就爆，觀眾會想看他會不會把真正的心裡話說出來。

# 主要驚喜或情緒回報
爸爸不是固執，是怕大頭爬高會摔、怕他把時間全丟進田裡；大頭說出小時候看過爸爸中暑倒在田邊，從此最怕這種天氣。兩人的擔心其實是同一個。

# 結尾畫面
黃昏田邊，大頭和爸爸一人一角把遮陽網慢慢拉平，爸爸教大頭綁一個慢慢的結；大頭的手從開場猛抓手機，變成穩穩拉著網。爸爸：「日頭會越來越凶，免驚啦。」大頭：「免驚不是一個人免驚，是一起免驚。」

# 上一集投票詞放哪裡
放在「大頭家客廳」節拍，爸爸用第 4 集最高票的詞反壓大頭：「整天在學校講『＿＿』，回家只會吼。」例如第 4 集最高票是「尊重」，爸爸就說：「整天在學校講『尊重』，回家只會吼。」若是「慢慢來」，就說：「整天在學校講『慢慢來』，催我架網催甲欲飛。」插槽設計成對比句，任何合理詞都放得進去，不必改節拍。

# 片尾投票題
題目：「你想幫五年後的大頭留哪一個詞？」
預期會出現的詞：「停」「免驚」「堅持」「卡慢咧」「你長大了」。
下一集怎麼用：第 6 集開場，大頭在整理畢業前的時間膠囊時，抽到同學寫的最高票詞；結尾他在手機備忘錄打出這個詞，補一句「我有做到了，但還是我」，作為他看見自己成長的觸發。
不雅字詞怎麼處理：採匿名投票，凡不雅字詞只出現「（被老蔡沒收的詞）」字卡，老蔡只說一句：「這個先保冷，畢業再還你。」該詞不進入選項；若最高票是不雅詞，改採第二高票，確保第 6 集能播出。

# 伏筆與回收
- 伏筆：開場老蔡問大頭「是天氣熱，還是你心裡在燒？」田邊爭吵時，大頭想起這句話，才停下來換說法。
- 伏筆：大頭進家門前先握緊手機，顯示他已經在忍耐；結尾他把手機放口袋，手空出來拉網。
- 回收：爸爸開場說「阮顧田顧幾冬啊」，結尾他教大頭打結，證明他不是拒絕大頭，只是不會說擔心。
- 回收：輝仔開場說「田會先中暑」，結尾大頭說「我是驚你閣倒一遍」，把「中暑」從開玩笑拉回情感重點。
