# 概念名稱
〈三秒〉

# 一句話故事
班群裡跳出一支學弟雙載、沒戴安全帽的影片，大頭火大到手指已經按在送出鍵上，他要在三秒內決定要不要把人罵上群組，結果發現那台車的煞車線早就斷了。

# 開場鉤子（前 10 秒）
教室後排，班群跳出一支手機拍的影片：學弟小安騎車衝下校門口斜坡，後座同學沒戴安全帽，群組裡一排笑臉。大頭一邊吼「誰拍的！」一邊打字，手指停在送出鍵上，耳朵紅、手在抖。輝仔坐在旁邊，只看了他一眼。

# 主角目標與主要阻礙
目標：讓小安知道這樣很危險，而且要讓他當眾丟臉，好讓大家知道「大頭不怕惹事」。
阻礙：大頭自己的衝動（一秒都不想等），以及他愛面子，怕被說「你在護著他」。

# 核心故事引擎（為什麼會一直想看下去）
觀眾會想知道：大頭會不會按下去？按了會怎樣？影片裡的斜坡到底發生了什麼？這個懸念從第一秒撐到第三分鐘，中間每個場景都會把答案往後推一點點。

# 主要驚喜或情緒回報
大頭以為小安是故意亂騎，其實阿蓮在機車行已經看出前煞車線斷了，小安是「騎到坡下才發現煞不住」，還硬撐著把同學載回學校。大頭的怒氣沒有地方去，只能變成一句很小聲的「你有沒有怎樣」。

# 結尾畫面
校門口斜坡，大頭和小安一起推車下坡，大頭的手機還亮著，班群的草稿寫著「斜坡慢慢推，我陪你」，還沒送出，他的手穩穩地拿著。

# 上一集投票詞放哪裡
插槽在第 1 集、第 2 拍：
- 版本甲（投票詞是袖口補丁的圖案，例如閃電、愛心、反光）：大頭的書包側袋有一小塊這個圖案的補丁，他在第 2 拍把書包抱在胸前，等於用它提醒自己慢下來。圖案不必解釋來源，只當成他身上的記號。
- 版本乙（投票詞是大頭想吼人之前心裡喊的詞，例如「停」、「等一下」、「三秒」）：第 1 拍他在心裡念的，就是這個詞，念三遍，每一遍都比上一遍慢。
- 換成任何合理的詞都放得進去，因為插槽只是「一個被念出來或被看見的記號」，不靠詞本身的意思推劇情。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）
題目：「你在生氣、快要說出口的時候，會先做什麼？」
預期詞：深呼吸、數數、先走開、喝水、冷靜、停、等一下。
下一集用法：最多人寫的詞會變成第 3 集班級健走隊的隊名，例如「深呼吸隊」，出現在白板表格的最上面一格。
不雅字詞：若學生寫出罵人或髒字，系統直接不列入計票，改以「請寫一個你平常用的替代詞」收集，不在片尾公開。

# 伏筆與回收
- 阿蓮在機車行把煞車線拿在手上，不解釋，只在第 4 拍讓觀眾看到「斷掉的那一段」。
- 小安答應「修好前不載人」，第 3 集可以用他的一句話帶過（不必重提）。
- 大頭的草稿沒送，第 5、6 集可以再出現一次「按下送出前的停頓」。

# 適合 AI 影片生成的理由（場景數、有台詞角色數）
- 場景 3 個：教室、機車行、校門口斜坡，不需要換很多背景。
- 有台詞角色 4 個：大頭、小安、阿蓮、老蔡（輝仔不說話，只有眼神）。
- 沒有追逐、沒有摔車、沒有快速動作，騎車只用靜態的車與推車畫面呈現。
- 一次只有一個人說話，符合硬規格。

# 自評：最大的風險
1. 阿蓮修車的段落容易變成「她用專長解決問題」，要讓大頭的停頓才是主因，阿蓮只負責把事實擺出來。
2. 小安的承認若寫得太完整，會變成說教；他要用自己的語氣說，不能像在做宣導。
3. 「無照騎車」與「雙載」只能以「不騎、不載」收尾，不能讓觀眾覺得他們被默許。
