# 轉角先停

# 一句話故事

大頭在校門盲轉角看見阿蓮騎腳踏車差點撞到人，第一反應是衝上去吼她；但被拱到快爆氣時，他第一次真的停住，改用一句話讓阿蓮自己下車牽過轉角。

# 開場鉤子（前 10 秒）

校門側邊的盲轉角，阿蓮戴好安全帽、騎腳踏車慢慢靠近。大頭突然伸手攔在她前面，拳頭握緊，嘴巴張開。

遠處一台腳踏車從另一側出現，兩人都急停，沒有碰撞。

大頭脫口而出：「你——」

畫面停在他快要吼出來的表情，以及阿蓮抓緊煞車的手。

# 主角目標與主要阻礙

大頭的目標，是讓阿蓮承認剛才騎過盲轉角很危險，並且不要再用「我有煞車」帶過。

主要阻礙有三個：

1. 阿蓮沒有受傷，也確實有戴好安全帽，覺得大頭反應太大。
2. 輝仔在旁邊冷冷補一句：「你現在的臉，比剛剛那台車還像要衝出去。」
3. 大頭的手已經抓住腳踏車龍頭，想直接把車牽走，情緒先跑在道理前面。

他不是不知道交通安全，而是被「差點出事」嚇到後，立刻把害怕轉成火氣，想用吼叫控制現場。

# 核心故事引擎（為什麼會一直想看下去）

同一個盲轉角裡，大頭連續面對三次選擇：

第一次，他差點先吼阿蓮。

第二次，阿蓮反問他是不是把自己當老師，大頭想把腳踏車推走，直接替她做決定。

第三次，輝仔故意用冷笑話拱他：「要不要我幫你把喇叭裝在嘴巴上？」

大頭每一次都被推到情緒邊緣。觀眾會想看他到底會不會又「先衝再說」，還是能在最後一秒停一下，讓對方也參與決定。

# 主要驚喜或情緒回報

阿蓮不是不知道危險。她剛才其實也看見轉角另一側有人，只是為了閃開路邊的大紙箱，視線被擋住，才沒有及早減速。

大頭原本以為自己是在「教她安全」，後來才看見自己差點用拉車、吼叫的方式，讓阿蓮在轉角更慌。

真正的回報不是阿蓮被說服，而是大頭鬆開抓住龍頭的手，退半步，說：「我剛剛很想罵你。可是先停一下，你要不要牽過去？」

阿蓮看著他，自己下車牽車。她沒有被命令，而是接住了大頭第一次沒有替她決定的伸手。

# 結尾畫面

大頭、阿蓮、輝仔和老蔡一起牽腳踏車走過盲轉角。到了看得見兩側的位置，阿蓮重新確認安全，扣好安全帽，慢慢騎走。

大頭站在原地，手掌從緊握變成攤開。阿蓮回頭問：「你這次不追著罵？」

大頭停半秒，回答：「我在練習停。」

輝仔在旁邊說：「那你的嘴巴還在實習。」

大頭想瞪他，手指先輕敲自己的手掌，忍住，只回：「免驚啦。」

# 上一集投票詞放哪裡

插槽放在第 5 拍，大頭從「抓住車龍頭」改成「鬆手」的瞬間。

若上一集是版本甲，袖口補丁圖案成為可見記號：他放手時，袖口被車把勾住一下，補丁露出來；大頭低頭看見它，手指改敲掌心，沒有再拉車。圖案不是解謎線索，只是他身上的小提醒。

若上一集是版本乙，投票詞成為大頭心裡先喊的短詞。他沒有直接大聲喊出來，而是在嘴邊停住，配合敲掌心的動作完成「先停一下」。觀眾能從他的口型和反應理解，卻不需要依靠畫面文字。

兩種版本都不會讓投票詞變成口號，而是成為大頭在情緒上來時的私人煞車。

# 片尾投票題（題目＋預期會出現的詞＋下一集怎麼用＋不雅字詞怎麼處理）

題目：**「下一集運動時，如果你快撐不住，你最想聽隊友說哪兩個字？」**

預期最多的詞：**我在**。

第 3 集會讓一名隊友在運動過程中停下來，不用催促或取笑，而是對另一名快放棄的人說「我在」，再陪他把動作做完。

投票介面可接受自由輸入，但以系統過濾不雅字詞；不雅或攻擊性內容不顯示，統一歸入「其他」，不讓它成為笑點，也不影響劇情投票。

# 伏筆與回收

- 開場大頭握拳，結尾手掌攤開，身體信號前後對照。
- 阿蓮一開始說「我有煞車」，後來主動下車牽行，表示安全不是只有設備，也包含看得到路況。
- 路邊的大紙箱一開始只是擋住視線，後來揭示它才是盲轉角的實際障礙；不需搬動大型布景，只要一個醒目的紙箱即可。
- 輝仔的「嘴巴像喇叭」冷笑話，回收在大頭最後忍住不追罵他。
- 老蔡只用兩個問句推進：「你抓住的是車，還是你的火氣？」、「你要替她決定，還是先問她？」不替學生說答案。

# 自評：最大的風險

最大的風險是「差點碰撞」若拍得太刺激，會變成交通驚險片，壓過大頭的情緒轉折。因此碰撞只用兩台車同時停下、煞車手部和大頭的反應交代，不拍危險衝刺。

另一個風險是老蔡的問句可能像說教，需讓大頭先做出錯誤選擇，再由他自己看見手上的力道，老蔡只負責把問題放到現場。阿蓮也不能只是被教育的對象，她最後主動下車、說出視線被擋住，並自己決定怎麼通過轉角。
