# 概念名稱：大頭卡路口

# 一句話故事
大頭被迫放學站導護，被阿炮笑到想落跑，卻發現自己一動，低年級學弟就跟著衝；他第一次在「丟臉」撲上來時先停下來，用浮誇姿勢把路口管成主場。

# 開場鉤子（前 10 秒）
放學教室裡，老蔡把反光背心遞給大頭。大頭手插口袋，不接：「我又不是導護媽媽。」老蔡只問：「你想不想讓全校看你的背影？」大頭立刻接過背心：「想。」接完發現自己被套住，耳根開始紅。

# 主角目標與主要阻礙
大頭目標：保住面子，證明站導護也很帥、不會被阿炮看衰。阻礙：他越想越覺得丟臉，總想脫背心逃走；阿炮還專門繞回來激他，逼他在「跑掉」和「留下來」之間選。路口低年級學弟又會模仿他，他不能示範錯誤，卻也拉不下臉承認自己怕丟臉。

# 核心故事引擎（為什麼會一直想看下去）
大頭被公開下戰帖，阿炮會回來檢查他是不是真的站到天黑。大頭嘴上越硬，身體越往路口外退；觀眾替他緊張：他會不會一時不爽就脫背心走人？他要用什麼台階下，既能先停住又保全面子？笑點從他「話說最滿、煞車最快」的落差來。

# 主要驚喜或情緒回報
大頭不是被講道理勸住，而是看到學弟要學他衝，他為了擋住學弟，反而第一個煞住自己。原來衝動派也可以在路口當煞車。最後他嘴硬說留下來是「想滷味要加辣」，但觀眾都看見他第一次自己先停。

# 結尾畫面
黃昏路口，大頭把反光背心穿成披風，揮指揮棒像權杖，對著停下來的車子臭屁喊：「過。」阿蓮說：「至少他停了。」輝仔小聲：「他以為自己是路權之神。」定格在大頭得意的臉，手不再抖。
