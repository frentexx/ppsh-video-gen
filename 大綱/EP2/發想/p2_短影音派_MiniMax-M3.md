# 概念名稱
先停一下

# 一句話故事
阿蓮的弟弟追球衝向慢車道，大頭腳抬起來想衝；這次他在「免驚啦」脫口之前先按住自己——用一聲喊話加一趟斑馬線，救人也救自己。

# 開場鉤子（前 10 秒）
放學路口，大頭拿手機自拍講到一半；畫面邊緣一顆球滾出，一個小男孩衝出去追。大頭腳一抬就要衝——鏡頭停在他鞋底懸空。一輛公車從畫面前方駛過，遮成黑。標題出。

# 主角目標與主要阻礙
目標：把小孩從慢車道邊拉回來。內在阻礙：身體已經啟動的衝動——口頭禪「免驚啦」衝到嘴邊、腳已經抬離地面。外在阻礙：慢車道有來車、視線被公車擋住、那路段沒有紅綠燈。

# 核心故事引擎
觀眾一直在問：大頭這次能不能搶在「免驚啦」說出口之前喊停？球在滾、孩子在跑、車要來，時間壓力讓每一秒都像在選。

# 主要驚喜或情緒回報
大頭真的停下了。他沒有「英雄式衝過去」，而是用喊、用斑馬線、用兩隻腳踩在地上把人帶回來。身體信號反轉：鞋從懸空到踩穩，呼吸從急到平。

# 結尾畫面
路口斑馬線前，綠燈剛亮。阿蓮牽著弟弟、老蔡站在後方、大頭站在斑馬線入口，沒人搶。鏡頭最後停在大頭的鞋：兩隻都踩在白線後。

# 上一集投票詞放哪裡
插槽發生在 beat 3（35–70s）大頭按下自己的那一拍，以及 beat 6（150–180s）大頭回老蔡的那個詞。
- 版本甲（袖口補丁圖案）：beat 3 大頭低頭看到袖口那塊圖（身上的記號），提醒自己「上次有人幫我補過，這次我要穩一點」。beat 6 老蔡問時，大頭指袖口說「這塊」。
- 版本乙（心裡喊的詞）：beat 3 大頭小聲唸出那個詞（「停／等一下／三秒」），腳停在半空。beat 6 老蔡問時，大頭再說一次那個詞。

# 片尾投票題
題目：「接力賽第一棒起跑前，你最想先喊什麼？」
預期會出現的詞：「停」、「等一下」、「沒關係」、「讓他先」、「一起」、「接給我」、「換你」等。
下一集怎麼用：第 3 集班隊練接力前，老蔡讓每個人喊一句當「起跑口號」；最高票的詞會被某一棒選手喊出來當反lag／破冰梗（例如「讓他先」變成默契信號，「接給我」變成交接用語）。
不雅字詞處理：製作單位先過濾，僅選「會讓同學笑或會被老師拿去用」的詞進榜，不公佈針對人或奇怪的詞。

# 伏筆與回收
- 小男孩（阿蓮弟）→ 第 3 集他可能在場邊看接力賽，被大頭隊友認出「那是上次那個弟弟」。
- 大頭的鞋從「懸空」到「踩穩」→ 結尾畫面的視覺回扣。
- 「喊」（第 2 集大頭對小孩喊）→「喊口號」（第 3 集接力賽起跑前喊）→ 同一張嘴，意思從「救人」變「起跑」。

# 適合 AI 影片生成的理由
場景集中在同一個路口，可拆成 3 個定點拍：路口邊人行道、斑馬線、斑馬線前等候區。大頭自拍的手機畫面可重複使用同一支手機的鏡頭感。有台詞角色只有 4 位：大頭、輝仔、阿蓮、老蔡；小男孩全程無台詞。

# 自評：最大的風險
「按下自己」偏內在，觀眾第一眼可能抓不到大頭為什麼停下。要靠「鞋懸空 → 踩穩」的鏡頭對比做視覺錨點，否則會變成「大頭自己跟自己對話」的尷尬內心戲。解法：拍 beat 2 時讓鏡頭特地停在他抬起的鞋底 2–3 秒，給觀眾時間讀到這個身體信號；beat 6 再回來對照一次，鏡頭語言就接上了。
