# 九十秒紅燈

# 一句話故事
大頭收到輝仔的訊息「你再不來就沒了」，隔著超長紅燈的路口急得想衝；他靠著「先停一下」撐完九十秒，才發現對面的「緊急」從頭到尾只是輝仔的冷笑話。

# 開場鉤子（前 10 秒）
特寫：路口行人號誌的紅色小人（畫面左側佔三分之一，夠大）。鏡頭下移，大頭的雙腳腳尖已經頂在停止線上，拳頭握緊、耳朵紅。對街長椅上，輝仔慢慢地、很有禮貌地揮手（觀眾一開始會以為他在「催人」，回看才發現他揮得很悠閒）。

# 主角目標與主要阻礙
目標：在輝仔「吃完」之前過到對街。阻礙：這個鄉間路口紅燈特別長，沒有車的時候看起來「根本沒必要等」；加上手機一直震，每則訊息都在加壓。

# 核心故事引擎（為什麼會一直想看下去）
觀眾和大頭一起被「到底對面有什麼要緊事」吊著。倒數的小人是看得見的時鐘，每一次大頭想動，鏡頭就切回小人；懸念不是「他會不會闖」，而是「他忍得住嗎，值得嗎」。

# 主要驚喜或情緒回報
反轉：所謂「緊急」是輝仔訊息的後半句被大頭自己漏看了——完整訊息是「你再不來就沒了，我的冷笑話」。他等了九十秒，換來一個冷笑話，還被笑。回報是大頭自己笑出來，而且身體是放鬆的：他發現「忍住」沒有輸。

# 結尾畫面
綠燈，小綠人走起來。大頭不再搶第一步，反而退半步讓阿蓮的腳踏車先過，兩人並排過街。鏡頭拉遠：大頭的拳頭是打開的，耳朵不紅了。與開場的握拳、紅耳朵對照。

# 伏筆與回收
- 開場輝仔「悠閒的揮手」→ 結尾才發現他根本沒在催。
- 阿蓮的安全帽、看小人的眼神→ 結尾兩人並排過街，她仍什麼都沒說教。
- 大貨車的影子（前三分之一）→ 讓大頭看見「衝出去的位置在哪」，不演車禍。
- 手機只讀到前半句→ 觀眾回看會發現畫面一直把後半句遮住（用角度、不是靠小字）。

# 自評：最大的風險
「訊息只讀到前半句」是靠觀眾理解的小動作，若表現不好會變成「大頭自己漏看」而非「輝仔使壞」。反轉的笑點有點輕，可能被評為「禮貌的冷笑話」；另外要確保貨車通過的畫面不被誤讀成危險或默許闖紅燈。
