# 概念名稱  
〈老蔡，你嘛變了〉  

# 一句話故事  
大頭撞壞老蔡的隨身小音響後，全班原本只想賠一台新的，最後卻錄了一份「說出你哪裡變了」的真心話送給老蔡，反過來逼出老蔡自己的改變。  

# 開場鉤子（前 10 秒）  
教室門口，大頭邊滑手機邊大步走進來，肩膀撞到準備進門的老蔡。老蔡手上的小音響滑落，摔在講台上，電池蓋「啪」一聲彈開。全班定格。輝仔小聲：「你邊走邊看手機，遲早。」大頭手抖舉起手，脫口：「免、免驚啦，我會賠！」講完自己愣住，慢慢放下手：「我……先停一下？」  

# 主角目標與主要阻礙  
主角大頭想趕快賠錢、恢復場面，不要讓「弄壞老師東西」變成全班的記憶；但他這次記得「先停一下」。主要阻礙：老蔡冷靜得太反常，不但不罵，還說「舊的不去新的不來」，讓全班更不安；而大家都不擅長當面說出自己的成長，尤其大頭愛面子，不想錄什麼肉麻話。  

# 核心故事引擎  
老蔡異常的平靜成為全班唯一想解開的謎。四個人越想知道老師真正的心情，就越得先說出自己的改變；當他們終於反問「老師你哪裡變了」，老蔡第一次被學生逼到當機。  

# 主要驚喜或情緒回報  
學生反客為主，用老蔡最常對他們做的事「點到痛處」，老蔡終於承認自己也在學；大頭沒有爆發，而是說出「我先停一下」。  

# 結尾畫面  
夕陽中庭，全班每個人找面對的人說一句「你這學期變＿＿了」。大頭用不抖的手搭輝仔肩膀：「你變敢講了。」輝仔對阿蓮：「你終於會說出來了。」阿蓮對老蔡：「老師，你也變了。」老蔡把摔壞的小音響抱在懷裡，耳朵紅掉，只擠出一句：「哎，這台不能丟了喔。」大家笑。

- **題目**：最後一集不上票箱，改成全校小活動——下課找一位同學，面對面說一句「你這學期變＿＿了」，然後把手放在自己心臟上三秒。  
- **預期會出現的詞**：勇敢、敢講、冷靜、好笑、變慢。  
- **下一集怎麼用**：本集為最後一集，無下一集；官方社群同步開放觀眾回報自己最常說的詞，最高票成為全劇最後一鏡的佈告欄彩蛋（後製字卡上字）。  
- **不雅字詞怎麼處理**：活動不錄音、不拍照、不搜集名字；如果聽到不雅詞，聽的人點頭說「好，我收到了」，不重複、不責罵。

- 老蔡的隨身小音響從系列固定小道具，變成主線契機；最後沒有被丟掉，反而被老蔡抱在懷裡，回收成「傾聽」的象徵。
