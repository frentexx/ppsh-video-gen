# 概念名稱：〈開學那一張〉

# 一句話故事
學期末大掃除，大頭從抽屜翻出去年開學寫的自我介紹字條；三人輪流唸出「過去的自己」，才發現都變了——最後讀到老蔡的字條，第一次看見老師也在「學」。

# 開場鉤子（前 10 秒）
大頭蹲在座位旁、手伸進陰暗抽屜深處，翻出一張皺黃紙條，攤開瞇眼，唸出第一句：「自我介紹──我是大頭，我脾氣很好的。」自己笑場，鏡頭切到阿蓮、輝仔也各自從抽屜／書包翻出一張。

# 主角目標與主要阻礙
目標：決定要不要把字條唸出來、讓別人看見「過去的自己」。
阻礙：唸出來等於當眾承認「以前的我比較差」，對愛面子的大頭很卡；輝仔習慣不先開口，要被推一把才讀。

# 核心故事引擎
每讀一張字條，就被迫把「過去的我」跟「現在的我」對照——觀眾會想看下一張是誰的、他撐不撐得住。

# 主要驚喜或情緒回報
老蔡從口袋掏出一張他留了一年的字條，唸出他寫給自己的話（坦白他當時也很緊張）；學生第一次「看見」老師也有情緒——角色互換完成，沒有人說教。

# 結尾畫面
四人背對鏡頭站在黑板前，黑板貼滿字條（後製字卡顯示各自寫下的「我變了」短句）；最後一個鏡頭是四人並肩看字條牆的剪影。

# 自評：最大的風險
最大風險是「讀字條」容易變靜態、變說教。已用三層手法避免：（1）大頭笑場製造迷因節奏；（2）阿蓮的肢體推一下打破文戲；（3）老師的字條設計成「自爆」式的坦白，不是金句。需在拍攝時特別保留「停頓與尷尬」的長度，不能剪太乾淨，否則說教感會跑出來。
