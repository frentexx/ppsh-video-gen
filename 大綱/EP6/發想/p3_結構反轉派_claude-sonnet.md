# 餅乾盒

# 一句話故事
學期末，老蔡搬出封存半年的大鐵盒，要每個人讀給「半年前的自己」的信；盒底多出一封老蔡自己從沒打開的信，學生逼他讀，他才第一次被點到痛處。

# 開場鉤子（前 10 秒）
教室櫃頂，一個圓形大鐵盒（餅乾罐款式，沒有品牌），盒蓋用一條紅色塑膠繩綁成大蝴蝶結。老蔡踮腳取下，用藍白拖輕輕踢開椅子，鐵盒放在講桌，蓋子發出「噹」一聲。四個人圍過來。

# 主角目標與主要阻礙
目標：讀完半年前寫給自己的信，看看自己變了沒。阻礙：每個人都怕讀出來丟臉，也都好奇老蔡那封「沒寫給任何人」的信寫了什麼。

# 核心故事引擎
前半段是輕喜劇：各人從信封抽出一樣東西（一張畫、一個預言、一顆糖），預言錯得離譜；後半段懸念：盒底那個藍色大信封，老蔡一直不讓人碰。

# 主要驚喜或情緒回報
反轉：老蔡的信不是給學生，是寫給自己；他半年前寫的願望是「半年後，我少說一句答案」。學生回看才發現：這半年他幾乎只問問題。當阿蓮問「老師，你現在是什麼感覺」，老蔡第一次講不出來，被輝仔接住，他說出一個詞。

# 結尾畫面
鐵盒再度蓋上，但這次大家各自放進一張新的紙條。紅繩重新綁成不太好看的蝴蝶結，是四個人一起綁的。老蔡的藍白拖在桌下搖了一下。

# 上一集投票詞放哪裡
165–180 秒：新紙條上面寫的就是第 5 集最高票的詞；各人念出自己要寫什麼，詞可以作為每個人加進盒子的物件（紙條、貼紙、畫）。換成任何詞都放得下，因為這是「給下學期的自己」的內容。

# 片尾活動
全校小活動，不花錢、不碰個資：每個班在教室後方放一個空鐵盒（或紙箱），學生用便條紙寫「一個給下學期自己的詞」，不署名、不留班級姓名，放進盒子。下學期開學由各班自行拆封。老師提醒不要寫他人名字或個資，不雅詞由導師先看過。

# 伏筆與回收
- 紅繩蝴蝶結（開場）→ 結尾由四人重新綁。
- 老蔡藍色信封，不讓人碰→ 讀出「少說一句答案」。
- 全集他只用問句→ 回看每集他確實只問問題（回顧插槽 B：此處可換成真實台詞片段）。
- 輝仔的冷笑話預言→ 他自己先說出內心話。

# 自評：最大的風險
整集靠「讀信」，容易變成口述心得、畫面靜態；回顧插槽若拼接不順會像剪輯串燒。老蔡的情緒詞若說得太完整，會變成說教。另要避免被看成畢業典禮式的結束，要保持「學期末、還有下學期」的語氣。
