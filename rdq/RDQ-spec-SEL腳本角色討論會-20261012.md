# RDQ 需求規格：SEL 影集角色與腳本討論會

## 一句話任務
Claude 先提出 Gemini 企劃的「接地氣修正案」與使用者討論定案，再做成一份現場投影用的 HTML 開會資料，蒐集同仁意見後回來確認角色定位與腳本方向。

## ✅ 已確認
- 流程分三段：①我提修正案 → 和使用者討論 ②做 HTML 開會資料、開會蒐集意見 ③意見帶回來，再確認角色與腳本方向（Ⅲ）
- 開會資料**不並列** Gemini 原版和修正版，直接呈現討論後的版本（Ⅲ）
- 與會者 **6 人以內**：學務處（生輔）、輔導老師（懂 SEL）、1 位行銷腦老師、帶班導師、熟悉新住民家庭的老師、**原住民教師**；**暫時沒有學生**（Ⅲ）
- 本校為**原住民重點學校**、也有不少**新住民第二代**：角色加入原住民學生（同一部影集，不另開一部），新住民第二代保留；兩種身分不疊在同一人、不疊加弱勢標籤（Ⅲ）
- HTML 用途：**現場投影**大家一起看（Ⅲ）
- 範圍：**4 個角色＋6 集大方向**，每集只談關鍵問題（Ⅲ）
- 簡潔易懂、不用技術名詞（Ⅰ）

## ❓ 假設
- ⚠️ 會議長度 → 預設 **60 分鐘**（決定能放幾個討論點）
- 會議紀錄由使用者在現場口頭主持、自己記錄，HTML 不做線上填寫
- 開會資料不放任何真實學生姓名或個案
- 製作方式（AI 生成）在開會資料裡只用一句話帶過

## ➕ 已採納（象限Ⅳ）
- 地雷檢查清單：**原住民微歧視**、新住民、家庭職業、暴力梗、真實歌名、家長觀感等，在會議中逐項確認

## ❌ 排除項
- 會前小調查、Gemini 原版與修正版的並列對照、會後決議單（這次不做）

## 📋 一段式需求規格
為屏北高中 SEL 影集《**高中生搞大事！**》（Gemini 產出，**6 集**、每集約 **2 分鐘**、角色**黑狗、阿蓮、輝仔、老蔡**）規劃一場 **6 人以內**（含一位**原住民教師**）、約 **60 分鐘**的同仁討論會。第一步由 Claude 提出接地氣的修正案（角色設定、6 集方向、要拿掉的不妥內容），與使用者討論定案，其中角色需加入**原住民學生**並保留**新住民第二代**、避免刻板印象與微歧視；第二步把定案內容做成**現場投影用的 HTML** 開會資料，不用技術名詞、每頁一個重點，內容包括角色卡、6 集各一個關鍵討論問題、地雷檢查清單；第三步使用者帶回同仁意見，再由 Claude 確認角色定位與腳本方向。
