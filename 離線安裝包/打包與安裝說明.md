# AI 影音環境：隨身碟離線安裝包

> 目的：這次在家裡安裝花了一個多小時（套件下載很慢），之後在別台電腦用隨身碟離線安裝，不必再下載。
> 建立：2026-10-15｜適用：三師爸工作流 `repo-16gvram-32gram`（16GB 顯卡＋32GB 記憶體版本）

## 一、為什麼不直接複製 `C:\AI`

Windows 的 Python 虛擬環境（venv）會把**本機 Python 的完整路徑**寫死在裡面，換一台電腦（使用者名稱不同、Python 裝在別處）就會壞。
所以隨身碟裡放的是「原料」，到新電腦再用腳本**離線重建** venv：

| 隨身碟資料夾 | 內容 | 從哪來 |
|---|---|---|
| `AI\` | `C:\AI` 底下的程式碼與模型，**不含 venv** | 兩台各自打包自己那部分 |
| `uv-cache-voice\`、`uv-cache-video\` | 所有 Python 套件（torch、cuDNN…），uv 的下載快取 | 家裡／學校各一份，分開放避免互相覆蓋 |
| `uv-python\` | Python 3.10、3.12（uv 管理的免安裝版） | 新電腦不必另裝 Python |
| `bin\` | `uv.exe`、`ffmpeg.exe`、`ffprobe.exe` | 新電腦不必另裝 |
| `hf-cache\` | bert-base-chinese tokenizer（BreezyVoice 用，不到 1MB） | 家裡 |
| `repo-16gvram-32gram\` | 三師爸 repo（套件清單、下載清單、程式） | 專案資料夾 |
| `install_offline.ps1`、本說明 | 安裝腳本 | 專案資料夾 `離線安裝包\` |
| `打包紀錄-voice.txt`、`打包紀錄-video.txt` | 每次打包的時間、來源電腦、各資料夾大小 | 自動產生 |

## 二、預估大小（256GB 隨身碟夠用）

| 部分 | 內容 | 約 |
|---|---|---|
| voice（家裡打包） | 套件快取 10～15GB＋Breeze TTS 2 7.1GB＋BreezyVoice 3GB＋whisper large-v3 3GB＋g2pW 0.6GB | 25～30GB |
| video（學校打包） | 套件快取約 8GB＋H3 41GB＋文字編碼器 24.6GB＋DMAD 2.6GB＋Qwen-Image 16.1GB＋Qwen-Image-Edit 28.1GB＋Music 3 11.1GB＋FlashVSR 6.3GB | 約 140GB |
| 合計 | | 約 170GB |

⚠️ **隨身碟必須是 exFAT 或 NTFS**。FAT32 單檔上限 4GB，H3 主模型一個檔就 21GB。新買的隨身碟大多是 exFAT；不確定就在檔案總管對隨身碟按右鍵 →「內容」看「檔案系統」。（`pack.ps1` 會自動檢查，遇到 FAT32 會停下來。）

## 三、打包（在已經裝好的電腦上做）

**前提**：該電腦的環境都已裝好、驗證通過，模型也下載完成；沒有 uv 正在執行。

在專案資料夾的 `離線安裝包\` 開 PowerShell（`E:` 換成隨身碟的磁碟代號）：

家裡 FrentexHome（語音）：
```powershell
powershell -ExecutionPolicy Bypass -File pack.ps1 -Dest E:\AI離線包 -Part voice -Test
```

學校 LIB-office（影像）：
```powershell
powershell -ExecutionPolicy Bypass -File pack.ps1 -Dest E:\AI離線包 -Part video -Test
```

- 兩台打包到**同一個** `E:\AI離線包`，各自只會加自己那部分，不會互相覆蓋。
- `-Test`：打包完會用隨身碟上的快取**離線**裝一個測試環境，最後印「✅ 離線測試通過」才代表這份包換到別台也能用。測試環境會自動刪掉。
- 可以重複執行：只會補上新增或變更的檔案。

## 四、在新電腦安裝

### 1. 新電腦要先具備
- Windows 11 64 位元、NVIDIA 顯卡。
- NVIDIA 驅動支援 CUDA 13：開 PowerShell 打 `nvidia-smi`，右上角 CUDA Version ≥ 13.0（不夠就到 NVIDIA 官網更新驅動）。
- C 槽空間：語音約 40GB、影像約 160GB（裝好後的大小，含 venv）。
- **不用**先裝 Python、uv、ffmpeg，隨身碟都有。

### 2. 執行
插上隨身碟，開 PowerShell（`E:` 換成隨身碟代號）：
```powershell
powershell -ExecutionPolicy Bypass -File E:\AI離線包\install_offline.ps1 -Part voice -AddPath
```
- `-Part voice`：只裝語音；`-Part video`：只裝影像；`-Part all`：全部。
- `-AddPath`：把 `C:\AI\_bin`（uv、ffmpeg）加到使用者 PATH，裝完要**重開 PowerShell** 才生效。

腳本會：複製程式碼與模型到 `C:\AI` → 用隨身碟快取離線建立每個 venv（`--offline`，保證不連網）→ 印出驗證結果。

### 3. 看到這些就算成功
- 每個環境印出 torch 版本與 `True`：Voice `2.14.0+cu130 True`、BreezeTTS `2.9.1+cu128 True`、BreezyVoice `2.7.1+cu128 True`、H3 `2.14.0+cu130 True`。
- `Voice 套件 ok`。
- 中間出現 `FutureWarning`、`SyntaxWarning` 是套件本身的提醒，不影響。

### 4. 失敗時
| 症狀 | 處理 |
|---|---|
| `No solution found` 或 `not found in cache` 之類，且有 `--offline` 字樣 | 隨身碟快取缺了那個套件：回到原本那台重跑 `pack.ps1`；或讓新電腦連網，把該環境的指令去掉 `--offline` 重跑（只會下載缺的） |
| `robocopy 失敗` | 隨身碟拔掉或空間不足，檢查後重跑（已複製的會跳過） |
| torch 印出 `False` | 驅動太舊，更新 NVIDIA 驅動 |
| 腳本中文變亂碼、語法錯誤 | 腳本必須是 UTF-8 with BOM；不要用記事本另存成其他編碼 |

## 五、注意
- **模型授權**照原專案 `THIRD_PARTY_NOTICES.md`：Qwen-Image 2.1、Breeze TTS 2 限非商業；MiniMax 系列排除美國／歐盟／英國／南韓。校內教學使用沒問題，隨身碟不要外流給校外。
- 隨身碟**不要放** `input_voice\`（校長聲音）、`input_pic\`（學生照片）；`pack.ps1` 只複製 `C:\AI`，不會碰到專案資料夾的這兩個目錄。
- 第一次在新電腦跑 `audio-separator`（分軌）會下載 BS-RoFormer 模型；若家裡已跑過 smoke test，它已在 `C:\AI\Voice\models\separator`，會一起打包。
- 套件快取的離線重建靠 uv 的快取機制。家裡打包時會用 `-Test` 實測一次；若失敗，備案是在網路快的時段（例如學校晚上）讓新電腦直接照 `AGENT_SETUP.md` 線上安裝。
