## 1. 兩片共同採用的轉換規則
1. **台詞原文逐字保留**。`line.text` 就是劇本原句（含標點、「……」）；只加 `tts` 讀音欄位（見第 3 點），不改字。
2. **一鏡只有一位說話者、一鏡一句（`line` 只能放一個）**：同一人連講的幾句，語意連貫的併成一鏡（〈黃線〉S11 兩句、S42、〈一針見血〉S06、S30、S42），其餘一句一鏡。
3. **說話者一定在畫面內**，`refs` 只放「要演戲的人」。無台詞的旁觀者（學弟妹、全班同學）**不進 `refs`**，只寫進 `frame` 提示詞，並要求失焦、不動、不說話（`extra_constraints`）。
4. **對話用單人近景互切**，不做過肩鏡或雙人說話鏡（H3 多人對話容易配錯嘴）。雙人／三人只在『動作交代』（坐下、並排縫）時用，且該鏡不說話。
5. **每鏡生成 4–12 秒，實際用多少由 `cut_in`／`cut_out`／`tail` 剪**：反應鏡與插入鏡生成 4 秒、剪成 2–3 秒用；台詞鏡 `cut_in` 0.3 秒（H3 常晚開口），`tail` 0.3–0.6 秒當喜劇停頓。沉默後才開口的台詞用較大的 `at`（例：大頭「丟臉」`at` 1.5–2.0 秒）。
6. **光線寫在每鏡 `frame` 開頭**，`cine` 是全片同一句（底片、鏡頭、調色），不含光線。兩片共用同一組光線句式：傍晚＝低角度橘色夕陽＋髮緣光；早晨教室＝窗光＋光束；中午器材室＝一道硬光束；窗在畫面哪一側由母版決定並重複寫進 `frame`（窗在畫面右側＝從前面往後看；窗在左側＝從後面往前看）。
7. **場景母版依「地點＋時段」建立**，同地點同時段的鏡頭裁同一張。〈黃線〉操場台階（傍晚）與器材室門口（中午）是同一棟建築、不同時段，所以拆成兩張母版（`steps`、`door_noon`）；〈一針見血〉教室早晨／傍晚也拆成兩套（`class_*`、`class_dusk`）。全片場景都不超過 3 個地點。
8. **動作都改成『原地可演』**：走遠、橫向走過、拿東西交接這類位移與雙人道具交接，一律拆成『站定＋表情＋台詞』或『特寫＋剪接暗示』（H3 帶人橫向走會跟拍、桌椅會滑）。
9. **道具鏡寫成『無臉特寫』**：針、布章、拳頭、小音響燈、袖口縫線。仍然放一位 `refs`（因為 H3 的 `subjects` 範例都有人；沒驗證空 `refs` 能不能跑），並在 `action` 寫 `The face never enters the frame`。
10. **道具標準描述兩片逐字相同**：小音響、黃色帆布袋、布章、深藍外套（第 2 節檔案：`共用_角色外觀.md`）。
11. **台語詞用國語讀音近似**（啥人、歹勢、見笑、免驚啦），不另找台語 TTS；容易讀錯的多音字用 `tts` 標：縫 `縫[:ㄈㄥ2]`、少 `少[:ㄕㄠ3]`、角 `角[:ㄐㄧㄠ3]`、數 `數[:ㄕㄨ4]`、朝 `朝[:ㄔㄠ2]`、重 `重[:ㄔㄨㄥ2]`、結 `結[:ㄐㄧㄝ2]`、歹勢 `歹[:ㄉㄞ3]勢[:ㄕ4]`、繃 `繃[:ㄅㄥ]`（第一聲不加數字，沒看過 README 範例，若挑音失敗再改）。`……` 在 BreezyVoice 前處理會被轉成逗號，所以停頓靠 `at` 與 `tail`，不靠省略號。
12. **make_film.py 不支援的全部移到 `後製待辦.md`**：旁白 VO、畫面外說話 OS、關鍵字卡、投票題、一鏡多句、切黑、動作音效庫（`amb` 只管 H3 原生音效，且只在確認聽寫沒有人聲時才採用）。
13. **片尾兩片完全相同**：2 張工具卡（3.0 秒）＋片名（3.5 秒）；用的特寫鏡不同（〈黃線〉S33、S35；〈一針見血〉S33、S45）。投票字卡不放在 `ending`，而是疊在最後一鏡。
14. **`seeds` 兩片都留空**，全部用預設；首幀看過 `_sheet.jpg` 再逐鏡補 seed。
15. **執行方式**：把 `template_local\` 的 `make_film.py`、`review.py` 複製進各片資料夾，`repo_dir` 已設為 `../../repo-16gvram-32gram`（從 `製作\<片名>\` 起算）。照 README 的三道人工關卡走。順序建議：**先只跑 `chars masters frames` 並看過 `_sheet.jpg`，再跑 `voices h3`**。

## 3. 製作風險排行（越前面越該先測）

### 〈黃線〉(v3)
1. **黃線針腳／裂袖口等道具一致性（S02、S07、S38、S17、S25，另 S10 帆布袋、S22、S42）**：打叉針腳、歪向右、亮黃色必須跨 4–5 鏡一致，而且是全片推理的核心。Qwen-Image-Edit 對細小針腳不穩，必要時需要改流程（附針腳貼圖當參考圖）。**建議最先做 S07 單鏡實測**。
2. **背景多人與位移鏡（S01、S03、S21 的背景旁觀者；S05 走向鐵門關門；S10 老蔡橫向走過）**：背景失焦的人 H3 會亂動；S10 的橫向走是 H3 弱項；S05 的『背影走進去、門關上』也是位移。這三個鏡頭失敗最可能，但可用備案降級。
3. **手部／拳頭特寫與情緒表演（S12、S19、S26、S27、S34、S31、S33）**：『拳頭握緊→顫抖→鬆開、手心指甲印』是全片的情緒線，但手部細節＋小表情變化是 AI 不擅長的；S33（大頭沉默後說『丟臉』）是情緒高點，需要多抽 seed 與人聽配音語氣。
- 其他：傍晚與中午的母版分開（光線連續性）、背景同學不亂動、台語詞念法。

### 〈一針見血〉(三師爸)
1. **三人鏡 S44、S49（及雙人鏡 S20）**：3 個參考圖同框，最容易融臉、多手；S49 用背影剪影降低風險，S44 是正臉並排，備案是拆鏡。這是兩片中**單鏡風險最高**的。
2. **手部與針線動作（S02、S09、S13、S31、S35、S36、S47）**：針掉落、穿線三次失敗、剪線穿針、五指貼滿小繃、六塊失敗品——劇本核心就是『大頭不會縫、偷偷練』，卻全在 AI 最弱的手部精細動作上。畫面以特寫帶過，細節靠音效與表情；這些鏡可能很多都要重抽。
3. **小音響小燈（S01、S21、S50、S52）與鏡數／工時**：小音響的 LED 燈亮／熄是全片象徵，但很小，H3 常忽略；另外鏡數 52、對話鏡多（28 鏡純說話），累計工時與重抽成本最高，後製（VO×4、OS、5 張字卡）也最重。
- 其他：全班群戲（S01、S04、S05 的背景同學）要『不動』、教室傍晚的 `class_dusk` 母版是全劇最需要先確認的（只剩一張椅子）、VO 與畫面的對時。

## 4. 需要人工決定的事
1. **本校制服款式**（`共用_角色外觀.md` 最上方）。
2. **阿蓮（排灣族暫定）、輝仔（越南新住民第二代）外觀需原住民教師、新住民相關老師確認**；族名也待確認。
3. 是否接受**劇本動作微調**（第 2 節兩張表，尤其〈一針見血〉S31 短袖改成縮進手臂）。要完全保持原文的動作，就得改外觀。
4. **兩片長度不同**（〈黃線〉約 165 秒、〈一針見血〉約 189 秒，含 9.5 秒片尾），比較實驗是否要拉齊？〈黃線〉已經為了貼近 180 秒加長了喜劇停頓（`tail` +0.4、無台詞鏡 +0.6 秒）。
5. **台語詞要不要真台語**：目前一律國語讀音。
6. **旁白／OS 的後製工具**：要用 BreezyVoice 另跑，還是由真人錄音？（建議先 BreezyVoice，與角色聲音一致。）
7. **黃線針腳備案**：若 Qwen 畫不出打叉針腳，是否允許附針腳貼圖（需改 make_film.py，違反『程式不用改』）或改畫面（例如只看到黃色縫線而不是針腳）。
8. 兩片都以 `seeds` 全空起跑：是否允許**逐鏡重抽**直到好看？（兩片的重抽次數會影響比較公平性，建議事先約定每鏡最多重抽 N 次，並記錄。）
9. 〈黃線〉S01 的西瓜是文字描述、S03 才是參考圖；〈一針見血〉沒用到西瓜。這個差異是劇本造成的，不是轉換手法不同。
10. 片尾一律『AI 工具名單』，是否另加『投票題』頁（目前放在最後一鏡的字卡）。
11. 16GB 記憶體很緊：**生成時整台電腦只做這件事**，不要同時開瀏覽器（`docs\hardware.md`）。

## 5. 驗證紀錄
- 兩份 `film.json` 已用 Python `json.load` 驗證為合法 JSON，並檢查：每鏡 `refs` ≤ 3、`dur` 在 4–12 秒、`scene` 的母版名稱存在、說話者都在 `refs` 內、`frame` 中的 `<imageN>` 都被替換、`chars` 區塊兩片**內容逐字相同**。
- 尚未實際生圖、生影，所有秒數與工時都是推估。
- 沒有修改 repo 內任何檔案。
